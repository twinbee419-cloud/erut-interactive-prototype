## 2. Codex 검토 요청

> 1~2는 반영 항목 일반 점검 · **3~9는 Claude가 반영하며 확신하지 못한 지점** — 대상 문서·규칙 이름으로 구체 대조해 주세요.

1. **A~D 반영 문구** — 세 문서 사이에서 서로 어긋나지 않는지 · 탐촉자 설정 문서 안에 `연결 채널 (필수)`·SN `인풋`을 전제로 한 서술이 남았는지(예: 콜아웃 "탐촉자를 **채널 단위로** 등록·관리").
2. **미배선 상태의 정의가 하나로 닫히는지** — '연결 채널 없음'이 트리 표시 · 표시명 규칙 · 장착 차단 · SN 빈칸 4곳에서 같은 조건을 가리키는지(듀얼에서 2행 모두 비움만 미배선인지).
3. **미배선 탐촉자가 다른 화면 목록에 섞이는가** — `[C-PRJ-05]` 측정 및 교정-사이드바 `탐촉자 선택` 드롭다운 · `[C-PRJ-05-02]` 일괄 교정 대상 · `[C-PRJ-03]` 종합 결과 차트 추가 트리(DAQ 장비 › 탐촉자 › 채널) · `[C-PRJ-04-01]` 탐촉자 모니터링 그리드 · `[C-PRJ-04]` DAQ 장비 모니터링 카드 '탐촉자 수' · `[C-PRJ-02]` 대시보드 '탐촉자 수'. 각 목록의 범위가 **채널 기준**인지 **등록 탐촉자 기준**인지, 미배선이 나타날 수 있는 곳이 있으면 보고. (기획 의도 = 미배선은 장착 불가 → 교정·측정 대상 아님)
4. **표시명 규칙** — 저장 후에도 유지되는 `(새 탐촉자-N)`의 **N 부여 규칙**(저장 전 임시 번호와 같은 값인지 · 재시작·재정렬 후 유지되는지)이 명세에서 정해지는지 · 붙여넣기 순번 ` (N)`이 `탐촉자명` **최대 20자**와 충돌할 때(원본이 20자) 처리가 정해지는지.
5. **기존 '프리셋 선택'과의 관계** — 탐촉자 설정 §프리셋 선택(`탐촉자명` 드롭다운으로 기등록 탐촉자의 설정값을 폼에 불러옴 · 연결 채널 제외)과 새 복사·붙여넣기가 **복사 대상 필드 범위**에서 같은지(프리셋 선택은 SN을 불러오는지) · 붙여넣기로 같은 이름(` (N)` 제외 시)이 여럿 생기면 프리셋 드롭다운 옵션을 구분할 수 있는지.
6. **'장착된 탐촉자는 채널을 비울 수 없음'의 우회 경로** — 탐촉자 설정의 `[저장]` 외에 장착 상태에서 채널이 사라지는 경로가 있는지: 트리 branch `항목 초기화` · leaf `삭제`(장착된 탐촉자 삭제 시 장착 탐촉자 슬롯 처리) · DAQ 장비 재연결로 **채널 수가 줄어** 기존 채널이 범위 밖이 되는 경우 · 듀얼에서 한 행만 비우는 경우.
7. **SN 자동 입력의 구현 가능성** — 재래식 단일·듀얼 탐촉자의 SN을 DAQ 장비가 채널별로 회신할 수 있는지(OEM 장비 SDK 기준 · 웹 조사 가능) · 수신 실패 시 표시 · 채널을 바꾸면 SN이 갱신되는지 · `[C-SET-02]` 장착 탐촉자 설정 '참조 4종'의 `시리얼 번호(SN)`가 빈칸일 때 표시. 참고: 이전 기획에 "탐촉자 SN은 config 파일에서 지정할 수 없음(하드웨어 제약)" 기록이 있음 — 자동 수신 전제와 충돌하는지.
8. **'먼저 등록 · 나중에 배선' 흐름이 연결 없이 가능한가** — 트리 구조(공통) "**Bridge PC 미연결 시 하위 항목(탐촉자·홀더·I/O 장비) 비활성**" 규칙과 `연결 채널` 옵션이 "연결 테스트 시 자동 획득한 채널 수"에 의존한다는 점 때문에, 장비 연결 전에 탐촉자 등록·복사·붙여넣기가 막히는지. 막힌다면 B의 목적("배선 전 등록")과 어긋나는지 보고.
9. **붙여넣기 '즉시 저장'과 기존 저장 규칙** — 측정 준비 상태 컨텍스트 메뉴 전체 비활성 규칙에 `복사`·`붙여넣기`가 포함되는지 · 진행중 검사에서 붙여넣기 저장이 '설정 변경 시 검사 마감'(`[C-PRJ-03]` §설정 변경 시 검사 마감 · 배치 밖 항목 예외)을 일으키지 않는지 · '화면을 닫으면 복사값 소멸'의 '닫음'이 문서 탭 닫기인지 다른 화면 이동까지 포함하는지.
