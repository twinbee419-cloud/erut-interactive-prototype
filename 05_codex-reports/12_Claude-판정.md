### S8 판정 상세

**`[C-RPT-01]`의 `ToF × 음속 ÷ 2`는 영점 누락. 정본 = `(ToF − 영점) × 음속 ÷ 2`.**

- 1순위 자료는 두 형태를 모두 씀(`초음파_기초_원리.md §704` · `기본원리_가이드.pdf §13` = 영점 없음 / `초음파_기초_원리.md §401` = 지연 포함). **`(ToF − 영점)` 형태는 자료에 문자 그대로 없고, 영점 교정 서술(`FastView §351~353 · §359`)에서 유도한 식**임.
- 결정 근거 = `03_dev_handoff/Report_Export_Spec_v1.0.md:100-101` — 저장값 `TB_MEASUREMENT.TimeOfFlight`(raw · 송신 펄스 기점)에 영점이 이미 빠진 ToF용 식을 적용하고 있음.
- **수정 보류** — `TimeOfFlight`가 raw로 저장되는지가 전제인데, **사용자 지시로 구현 확인을 생략**함. 수정 대상 3곳(`Report_Export_Spec:101` · `NDT_Expert_Review:116` · Notion `[C-RPT-01]`)은 그대로 둠.
- 파생 발견 — `(ToF − 영점) × 음속 ÷ 2`의 결과는 **음로**이고 **깊이 = 음로 × cos θ**. `10_RPT04` 초안의 `깊이` 라벨은 사각 채널에서 틀림 → `음로`로 변경 검토 중(사용자 결정 대기).

## 2. 이번 라운드 신규 반영 — TCG 입력 방식

### `[C-PRJ-05] 교정-사이드바` ④ 감도 보정 · TCG

| 항목 | 내용 |
|---|---|
| **입력 방식 토글** | `자동`(기본) / `수동` 세그먼트 토글 신설 |
| 자동 | `[✨]`만 포인트 표에 값을 씀 · 표 readonly |
| 수동 | `[✨]` 숨김 · 표 직접 편집 · `[+]`·`[🗑]`·`ToF` 수정은 수동에서만 |
| **표 공유** | 두 모드는 포인트 표 1개를 공유 · **모드별로 따로 보존하지 않음** |
| **전환 시 값 유지** | 자동 → 수동 / 수동 → 자동 모두 표 값 그대로 |
| **`[✨]` 재실행** | **확인 없이 즉시 덮어씀** · 직접 수정한 값이 있어도 동일 |
| 교정 이력 | `[교정 완료]` 시점의 모드를 `TCG 입력 방식`으로 기록 |
| 방식별 액션 버튼 | TCG `[✨]` 위치 = 입력 방식 토글 아래(자동 모드에서만) |

**판단 근거**

- **값 유지** — 수동으로 넘기는 주 용도는 자동 결과에서 평탄화되지 않은 깊이만 다듬는 것. 비우면 전 포인트를 시편 에코로 다시 잡아야 함.
- **표 공유** — TCG ↔ DGS는 보정 방식 자체가 달라 입력값을 따로 보존하지만, 자동·수동은 같은 표를 누가 쓰느냐의 차이.
- **팝업 없음** — 자동 버튼을 누른 것 자체가 덮어쓰기 의사. 날아가는 것은 Gain 숫자 몇 개라 재입력 비용이 작음. `[C-PRJ-06]`에도 같은 원칙 적용.

부수 수정 — 같은 문서 DGS 쪽의 한글 오타 2건(`바뀜고` → `바뀌고` · `바뀜므로` → `바뀌므로`). 상태 `완료` → `진행중`.

## 3. Codex 검토 요청 — `[C-PRJ-05] 교정-사이드바` 화면 단위 재검토 1회

1. **입력 방식 토글 서술이 문서 안에서 모순 없이 읽히는가** — 특히 ④ 상단의 *"방식을 전환해도 각 방식의 입력값은 그대로 유지(보존 단위는 채널별)"*(TCG↔DGS)와 새로 넣은 *"자동·수동은 따로 보존하지 않음"*이 혼동 없이 구분되는가.
2. **자동 모드 표가 readonly인데 `ToF`는 "게이트 TOF와 연동해 자동 입력"** — 자동 모드에서 `ToF`를 누가 채우는가(`[✨]`가 에코를 찾아 행을 만드는가, 사용자가 수동 모드에서 만든 행의 ToF를 쓰는가). 구현 가능성 관점에서 비어 있는지.
3. **`Probe_Registration_Spec` §3.2 ↔ Notion `[C-PRJ-05]` ④** 대조.
4. **교정 이력에 `TCG 입력 방식`을 기록한다고 적었는데** 그것을 보여줄 `[C-PRJ-05-01] 교정 이력` 감도 상세 모달에는 아직 항목이 없음 — 이건 Claude가 이미 인지한 건이라 **발견 보고 불필요**(§4 참조). 다른 문서(`Result_Analysis_Storage_Spec` 등 저장 스키마)에 이 값이 빠져 있는지만 봐 주면 됨.

결과는 `13_Codex-재검토.md`로.
