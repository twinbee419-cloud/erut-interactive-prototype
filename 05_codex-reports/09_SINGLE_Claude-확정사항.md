## 0. 결론부터 — 신규 화면은 만들지 않는다

처음에는 `[C-PRJ-07] 빠른 시작`을 신설하려 했으나 **폐기**했다. 최종 형태는 이렇다.

| | 내용 |
|---|---|
| **신규 화면** | `[C-RPT-04]` **1개만** (캡처 보관함) |
| **확장** | `[C-PRJ-05]` — 교정 전용 → **교정 + 단일 탐촉자 측정** |
| **변경 없음** | `[C-PRJ-01]` 시작 페이지 — '빠른 시작 모드' 카드 **넣지 않음**(Figma에 한 번 들어갔다가 철회) |

**"빠른 시작"은 별도 모드가 아니라 홀더·I/O 설정을 건너뛴 기본 경로다.** 그래서 분기 자체가 필요 없다.

## 1. 확정 사항

### 1-1. 플로우

```
DAQ 설정/연결  →  탐촉자 등록  →  교정(= [C-PRJ-05])  →  A-scan 확인 → 캡처
                                                              ↓
                                                        [C-RPT-04] 보관
```

- **홀더 · I/O 장비 설정은 하지 않는다.** 따라서 엔코더도 없다.
- 모재 · 배치 · 스캔 계획도 거치지 않는다.

### 1-2. 검사로 기록하지 않는다

단일 탐촉자 측정은 **검사(inspection) 엔티티를 만들지 않는다.** `[C-PRJ-03] 종합 결과`를 거치지 않으며, 결과물은 **캡처뿐**이다.

> 이 때문에 `[C-PRJ-03]`의 ▶ 선행조건 6가지(배치 저장 · 스캔 계획 저장 · 엔코더 캘리브레이션 · 검사 시작 트리거 등)는 이 경로에 적용되지 않는다. `[C-PRJ-05]`의 ▶는 이미 **조건 없이 바로 수신**으로 확정돼 있다(2026-11-03 · `00_재검토_대기열.md` B 참조).

### 1-3. 교정은 필수다 — 생략 불가

`01_materials/한국_비파괴_초음파_검사_업무_프로세스.pdf` Step 2.2 ④가 교정을 4종으로 정의하며, 앞 3개는 조건 없이 필수다.

| | 항목 | 비고 |
|---|---|---|
| a | **거리(시간축) = 음속** | 음속을 넣어야 가로축이 시간(μs) → 깊이(mm)로 변환됨 (`초음파_기초_원리 §469`) |
| b | **영점(Probe Delay)** | 단일 게이트 방식에서는 영점부터 게이트까지가 곧 두께 (`FastView §352~353`) |
| c | **감도(80% FSH)** | 자료에 **면제 규정 없음** |
| d | DAC/TCG | **"(해당 시)"** — 유일한 조건부. 두께만 재면 불필요 |

- **경사각**은 종파 수직 탐촉자에서 성립하지 않으므로 제외.
- 참고 — 게이트 2개로 `두께 = (T2−T1) × 음속 ÷ 2`를 쓰면 영점이 수식에서 소거되지만(`초음파_기초_원리 §396~412`), ERUT는 전체가 **단일 게이트 + 영점**이라 채택하지 않았다.

### 1-4. 교정 주기 = 기본 4시간

1순위 자료 두 건이 서로 다르다. **사용자 결정으로 4시간 채택.**

| 자료 | 주기 |
|---|---|
| `한국_비파괴_초음파_검사_업무_프로세스.pdf` Step 3.3 | 검사 중 매 **2시간**마다 (또는 규격 지정 주기) |
| `상용 소프트웨어(FastView) 기능 정리본.md` §224 | 원자력 법규상 **4시간** |

현행 `[C-SET-06]`·`[C-PRJ-05]`의 기본값 4시간과 일치하므로 **변경 없음**.

### 1-5. 캡처(스냅샷) 버튼

- **위치 = 파형 영역 우측 상단**, `교정일시` 우측.
- 아이콘은 `[C-PRJ-03]`·`[C-PRJ-06]`의 캡처와 **동일 모양**(프레임 모서리 + 사각형).

### 1-6. `[C-RPT-04]` — 캡처 보관함

| | 내용 |
|---|---|
| 성격 | **보관 전용** · **보고서 생성 없음** |
| 보관 데이터 3종 | ① **A-scan 캡처** ② **모재 마킹 사진**(첨부) ③ **메모** |
| 동결값 | **음속 · 영점 · 감도(Digital/Analog) · 게이트(Start·Width·Threshold) · 캡처 일시** |

**엔코더·좌표는 포함하지 않는다.** A-scan 스냅샷은 한 점에서 찍은 파형이라 좌표 개념이 없고, 이 플로우는 엔코더 자체를 연결하지 않는다. **"모재의 어디인가"는 좌표 대신 첨부 사진과 메모가 담당한다** — 수동 검사에서 검사자가 모재에 직접 표시하고 사진으로 남기는 실제 방식과 같다.

> 동결값을 넣는 이유 — 보고서를 내지 않더라도, 나중에 그 캡처를 보고 "게인 몇 dB에서 찍었나"를 모르면 다른 캡처와 비교가 성립하지 않는다. 같은 결함도 게인이 6dB 다르면 전혀 다르게 보인다.

### 1-7. 파형 영역 헤더 — 완료 칩 접힘/펼침

칩 5종을 헤더에 나열하던 것을 **`교정일시` 드롭다운 안으로 접었다.**

| 상태 | 표시 |
|---|---|
| 교정 이력 **없음** | `교정일시 —` · 드롭다운 화살표 없음 |
| 전부 유효 | `교정일시 YYYY-MM-DD HH:MM` 평상 색 |
| 일부 문제 | `교정일시` **빨강** + 해당 칩 `(!)` |

**칩 3상태**

| 칩 | 뜻 |
|---|---|
| 비활성 | 아직 안 함 |
| `✓` 파랑 | 완료 |
| **`(!)` 빨강** | **무효화 · 재교정 필요 — 다시 해야 함** |

- 무효화(선행값 변경)와 재교정 필요(주기 만료·이벤트)를 **하나로 합쳤다.** 사용자가 할 일이 "그 단계를 다시 하세요"로 같기 때문이다.
- **미완료는 빨강으로 쓰지 않는다.** 처음 교정을 시작하면 전 항목이 미완료인데 그게 빨강이면 경고가 아니라 노이즈가 된다.
- **종파 채널은 `경사각` 칩을 숨겨 4종**으로 표시한다.

### 1-8. ERS 배지 — 교정 화면에도 표시

`[C-PRJ-06] 결과 분석` 전용이었으나 **`[C-PRJ-05]`에도 표시**한다.

표시 조건은 동일 — **DGS 채널 · 기준 에코 기록 완료 · 게이트가 피크 포착**. TCG 채널이나 기록 전에는 배지 자체가 뜨지 않는다.

> 근거 — 크기를 아는 반사체(φ3 FBH)를 짚었을 때 `ERS 3mm`가 나오면 교정이 맞은 것이고, 엉뚱한 값이면 기준 에코를 다시 기록해야 한다. **교정이 제대로 됐는지 검증하는 수단**이므로 교정 화면에 있어야 한다.

## 3. Codex가 검증할 것

1. **`[C-PRJ-05]` 명칭 변경의 영향 범위** — 이 화면을 참조하는 문서가 몇 개이고 어디인지. 문서명 2개 + 본문 cross-reference 전부.
2. **검사 엔티티를 만들지 않는 것**이 `[C-PRJ-03]`·`[C-PRJ-06]`의 **`모재 1 : 스캔 계획 1 : 검사 1`** 전제와 충돌하지 않는지. 특히 `[C-PRJ-06]`은 "완료(마감)된 검사"만 불러오는데, 캡처만 있고 검사가 없는 데이터가 어디에도 걸리지 않는지.
3. **`[C-RPT-04]` ↔ `[C-RPT-02]` 기능 중복** — 둘 다 "캡처 보관함"이다. 경계가 A-scan / C-scan으로 충분히 갈리는지, 메뉴·진입점이 겹치지 않는지.
4. **`[C-PRJ-01]` 시작 페이지** — Figma에 '빠른 시작 모드' 카드가 들어갔다가 철회됐다. 현재 Figma와 Notion 명세(카드 3장)가 일치하는지.
5. **칩 3상태**가 `[C-PRJ-05] 교정-사이드바` §섹션 간 의존 관계의 **무효화 전파** 서술과 맞물리는지. 그 절은 무효화를 `재수행 필요`로 적고 있다.
6. **홀더·I/O를 건너뛰는 경로**가 다른 화면의 선행조건·필수 항목과 부딪히지 않는지. 예 — `[C-SET-02] DAQ-탐촉자 설정`이 홀더 등록을 전제하는 서술이 있는지.

`[C-PRJ-05]`는 필터를 **교정 ①~⑤ 중 ⑤**로 두고 있으나, 자료는 교정으로 분류하지 않는다.
