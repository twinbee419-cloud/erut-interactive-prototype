## 2. Codex 검토 요청

1. **DAQ 장비 화면 수정 범위** — '현재 배치에 연결된' 판정 기준(배치 미저장·배치 변경 중 · DAQ 장비가 여러 대 등록된 경우의 해석)과, 수정 가능한 항목(배치 안 된 홀더 · 장착 안 된 탐촉자)을 고쳤을 때 측정 준비·진행중 검사에 영향이 없는지(트리 컨텍스트 메뉴 전체 비활성 규칙과의 충돌 포함).
2. **F6/F7 화면별 동작** — 문서 탭 전환·모달(일괄 교정·팝업) 위에서의 F6/F7 · 측정 및 교정에서 F6으로 파형 수신을 켠 직후 탭을 떠날 때 · F7 '그 외 화면'의 범위가 각 문서에서 같은지.
3. **연결 끊김 처리** — Sight → Bridge PC 구간만 끊긴 경우(`[C-NTF-01-01]` '알림에 포함하지 않는 항목'의 "Bridge PC 환경에서는 프로그램과의 연결이 끊겨도 데이터 수집이 계속" 서술과의 관계) · `[C-PRJ-03]` `DAQ 장비 연결 필요` 팝업 \[설정\] 이동 대상(장비 정보)과 복구 순서의 연결 패널(Bridge PC 설정)이 다른 점 · 상태바 dot 표시.
4. **일괄 완료 = 사이드바 완료 기준** — `[C-PRJ-05-02]` 완료 조건 문구가 `[C-PRJ-05]` 사이드바의 실제 필수 표시·자동 탭 전환·DGS 유효 조건과 1:1로 맞는지 · 일괄 \[완료\]의 '미충족 채널은 교정값만 저장'이 사이드바의 '필수 미입력 시 저장 차단'과 상충하지 않는지.
