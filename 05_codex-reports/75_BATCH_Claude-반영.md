## 2. Codex 검토 요청

> 1~2는 반영 항목 일반 점검 · **3~7은 Claude가 반영하며 확신하지 못한 지점** — 구체적으로 대조해 주세요.

1. **S1~S5·N1·보완 반영 문구** — 일괄 교정 · 사이드바 두 문서 사이에서 서로 어긋나지 않는지 · "원인 여러 개 나열"의 잔존 서술이 두 문서 어디에도 남지 않았는지.
2. **사유 3종 ↔ 이동 규칙 3종 ↔ 다중 사유 우선순위**가 1:1로 닫히는지.
3. **S5 '[닫기] 시 전 페이지 입력값 폐기' ↔ 교정 상세 모달 `[저장]`** — 교정 상세의 `[저장]`("전 채널의 교정값을 각 채널 고유값 그대로 저장")이 **즉시 영구 저장**인지 **일괄 교정 모달의 세션값**인지 명세에서 정해지는지. 전자면 일괄 `[닫기]` 폐기 규칙과 충돌(교정 상세에서 저장한 값은 남음) · 후자면 교정 상세 `[저장]` 문구가 오해를 부름.
4. **S1 '진행 순서상 첫 필드 focus' ↔ 사이드바 탭 구조** — 진행 순서를 Pulser Control → 영점 → … → 시험편으로 적었는데, 사이드바 탭은 `교정 / Pulser Control / 시험편 정보` 순서임. Pulser Control 탭의 미입력과 교정 탭 ① 영점의 미입력이 동시에 있을 때 '첫 필드'가 Pulser Control 탭으로 전환되는 것이 `[교정 완료]` 필수 미입력 처리(해당 탭으로 자동 전환)와 모순 없이 읽히는지.
5. **S2 '가장 최근 원인 1개' ↔ DGS 재기록 트리거 7종** — 사이드바 ④ DGS는 7종 변경 시 "기준점 3종을 비우고 곡선 삭제 + 얼럿"이라고 따로 정의함. Pulser 변경이 ④를 `재수행 필요 (Pulser Control 변경)`로 만드는 동시에 DGS 얼럿·기준점 삭제도 일으킬 때, 두 표시가 중복·충돌 없이 함께 정의돼 있는지 · 재수행 표시 해제 조건("섹션 다시 완료")이 DGS에서는 "기준 에코 재기록 완료"와 같은 뜻인지.
6. **보완 ⚠ 판정 기준** — `[C-PRJ-03]` 차트 추가 트리의 "교정 필요 채널(교정 미완료 · 재교정 필요)"과 `[C-PRJ-04-01]` 탐촉자 모니터링의 재교정 필요 셀, 그리고 일괄 교정 결과 팝업의 '미완료'가 **같은 판정 소스**를 가리키는지 · 다른 정의가 있으면 보고.
7. **S4 ToF error 색 ↔ pane '신호 미수신' 표시** — `[C-PRJ-05-02]` §채널 pane의 "신호 미수신 시 안내 문구 + 게이트 미설정으로 간주"와 Echo 실패 error 색이 같은 pane에 동시에 나타날 수 있는지 · 그 경우 우선 표시가 정해져 있는지.
