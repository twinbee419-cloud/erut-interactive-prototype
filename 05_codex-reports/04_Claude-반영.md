## 1. S4 게이트 선택 경로 — **양방향 동기로 해소**

`측정 게이트`는 A인데 파형에서 B를 클릭하면 `[✨]` 대상과 `[↑ Record]`가 저장할 기록 게이트가 어긋날 수 있다는 지적. 정확하다.

**해소 방향 = 값을 하나로 묶는다.** 선택지는 둘이었다.

| | 처리 | 채택 |
|---|---|---|
| 가 | DGS 설정 중 파형 클릭 선택을 **비활성**, 드롭다운만 유일한 수단 | ✗ — 다른 단계에서 되던 조작이 갑자기 막혀 이유를 알기 어렵다 |
| 나 | **양방향 동기** — 어느 쪽을 건드려도 같은 값이 따라온다 | **✓** |

**반영** — `[C-PRJ-05] 교정-사이드바` ④ `측정 게이트`에 추가.

- DGS 설정 중에는 드롭다운 ↔ 파형 선택 게이트가 **양방향 동기**. 값이 하나라 **어긋나는 상황 자체가 생기지 않는다.**
- 파형에서 다른 게이트를 클릭하면 게이트가 바뀐 것이므로 **성공 상태 해제 조건 1번에 해당** — `[✨]`를 다시 눌러야 한다.
- **`② 음속`의 Echo 행은 행마다 게이트가 따로**라 기존대로 **단방향**(사이드바 → 파형)을 유지한다. 양방향으로 하면 어느 행과 동기할지 정할 수 없다.

## 2. 저장 예시의 TCG/DGS 동시 기재 — **채널을 분리**

`§3` JSON 예시 한 채널에 `tcgPoints`와 `dgs`를 함께 적어 두고 바로 아래에서 택일을 요구한 모순. 예시를 **2채널로 분리**했다.

- `CH 02` = TCG 채널(`tcgPoints`만) · `CH 03` = DGS 채널(`dgs`만)
- 택일 규칙 문장에 **"위 예시의 `CH 02`는 TCG 채널, `CH 03`은 DGS 채널이다. 한 채널에 둘을 함께 두지 않는다."**를 붙여 예시와 규칙이 서로를 가리키게 했다.

## 3. S6 예외가 일반 규칙에 없던 문제 — **본문에 직접 표기**

`④`에만 예외를 적고 `섹션 간 의존 관계`에는 안 적어, 일반 규칙만 읽으면 다르게 구현될 수 있다는 지적. 타당하다.

**반영** — `섹션 간 의존 관계` 섹션에 두 곳을 고쳤다.

- 제목 보조문구 : `(순서 강제 없음 · 게이팅 + 무효화 전파 · **단 DGS는 예외**)`
- 본문에 한 줄 추가 : **`④ 감도 보정의 DGS 블록만 입력 자체를 차단`** — ①영점·②음속 미완료면 블록 전체 비활성. 이유(가로축이 음로라 축 없이 기록한 기준점은 무의미)와 상세 위치(`④`)를 함께 적었다.
