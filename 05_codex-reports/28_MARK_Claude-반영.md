## 1. 판정 — 7건 모두 유효 · 전부 반영

| | 항목 | 반영 |
|---|---|---|
| **B1** | 자동 후보가 여러 채널에 걸칠 때 채널 미정 | **두 경로 모두 "추가 시점에 사이드바에서 펼친 채널 1개"**. 후보 사각형 클릭 시 검출 채널이 자동으로 펼쳐짐(여러 채널이면 에코가 가장 높은 채널) · `[마킹 추가]` 전 변경 가능 · 데이터 없음 검사도 펼친 채널 기준 |
| S1 | 미저장 Gain·Gate로 만든 마킹의 재현 | 추가 허용 · **그 채널의 Gain(Digital·Analog)·Gate(Start·Width·Threshold)를 마킹에 함께 동결 보관** |
| S2 | 최대 진폭 지점 기준 | **펼친 채널의 선택 게이트가 포착한 피크 중 영역 안 최대값 · 동률이면 더 얕은 지점** |
| S3 | 3D에서 행 클릭 | **2D로 전환 후 해당 영역으로 이동** |
| S4 | 일괄 실행 부분 실패·이탈·재실행 | 한 건 실패해도 다음 건 계속 · 재시작 시 `진행중` → `실패`(사유 `실행 중단`) · 완료 건 포함 확인 팝업에서 `[닫기]` = **선택 전체 미실행** |
| S5 | 즉시 저장 실패 | 추가 저장 실패 → 행 미생성·번호 미소비 + 인라인 문구 · **각 행 `진행중` 저장 성공 후에만 로봇 전송** |
| S6 | 캡처·마킹 경계 | 좌표는 추가 시점 **복사**(측정 사각형 수정·삭제와 독립) · **캡처 이미지에 마킹 오버레이 미포함**(캡처 = 동결 증거 / 마킹 상태는 이후 바뀜) |

사용자 확인 1건 — **3D View에서 마킹 추가 불가**(평면 좌표 산출 불성립 · 측정 도구와 같은 조건). 목록·실행은 3D에서도 가능.
