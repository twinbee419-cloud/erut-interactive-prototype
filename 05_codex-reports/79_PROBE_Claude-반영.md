## 2. Codex 검토 요청

> 1~2는 반영 항목 일반 점검 · **3~8은 Claude가 반영하며 확신하지 못한 지점** — 대상 문서·규칙 이름으로 구체 대조해 주세요.

1. **B1~N1 반영 문구** — 탐촉자 관련 4개 문서(트리 구조 · 탐촉자 설정 · 장착 탐촉자 설정 · Bridge PC 설정)와 개발 사양 2개가 서로 어긋나지 않는지.
2. **'장비 연결 전 하위 비활성' 잔존 서술** — 화면설계서 전체·개발 사양에서 "Bridge PC 미연결 시 탐촉자·홀더·I/O 장비 비활성"을 전제로 한 서술이 남았는지(예: `[C-SET-02]` 홀더 설정 · I/O 장비 설정 · `[C-HLP-01]` 사용 가이드 1단계 주석 · `[C-PRJ-04]` DAQ 장비 모니터링).
3. **연결 전 설정의 구현 가능성** — 홀더·I/O 장비 설정 중 **장비에서 받아오는 값에 의존하는 필드**(예: I/O 장비의 채널·트리거 관련 옵션 · 홀더의 장착 탐촉자 선택 목록)가 연결 전에 어떻게 동작해야 하는지 명세에서 정해지는지. 탐촉자만 `연결 채널`에 연결 전 규칙을 두었음.
4. **공통 팝업 개편의 파급** — `[확인]` = **저장 후** 이동·닫기로 바뀜. ① '저장'이 화면마다 다른 동작(`[저장]` 버튼이 없는 화면 · 저장 시 검사 마감 확인 팝업이 뜨는 화면 = `[C-PRJ-03]` §설정 변경 시 검사 마감 · 측정 준비 중 조회 전용 화면)일 때 팝업 `[확인]`이 무엇을 하는지 정해지는지 ② `공통 팝업 - 닫기`를 참조하는 다른 문서에 "폐기·clear" 전제 서술이 남았는지 ③ **저장하지 않고 떠나는 경로**가 사라졌는데(팝업에 '저장 안 함' 없음) 화면별 `[↺]` 되돌림 후 이동으로 충분한지 · `[↺]`가 없는 화면이 있는지 ④ `[C-PRJ-06]` 결과 분석: 교정값이 바뀐 상태의 `[저장]`은 **수정 정보 입력 모달**을 거치는데, 탭 닫기·검사 불러오기 팝업 `[확인]`(저장 후 진행)도 이 모달을 띄우는지 · 모달을 닫으면 어떻게 되는지 명세에서 정해지는지(`-파형 영역` 내보내기 팝업은 정해져 있음) · `-사이드바(교정)` `[↻]` 블록 "`[저장]` 전에 탭을 닫아 `공통 팝업 - 닫기`에서 `[확인]`을 누르면 초기화한 값이 저장됨"이 의도와 맞게 읽히는지.
5. **`공통 팝업 - 이동` 적용 범위** — 정본은 "화면 안에서 다른 항목으로 이동(예 트리 노드 전환)"로 정의함. 같은 성격의 이동(예 `[C-SET-03]` 모재 트리 · `[C-SET-04]` 프리셋 트리 · `[C-PRJ-06]` 검사 불러오기 · 장착 탐촉자 팝업 `[확인]` 이동)이 각 문서에서 이 팝업을 가리키는지, 다른 팝업·무확인으로 적힌 곳이 있는지.
6. **앱 종료 '전 탭 저장 후 종료'** — 여러 탭 중 일부만 저장 실패할 때 이미 저장된 탭의 처리 · 실패 탭 전환 후 사용자가 다시 종료를 누르는 흐름이 구현 가능하게 정해지는지.
7. **S6 장착 탐촉자 삭제 → 슬롯 `탐촉자` 비움** — 비워진 슬롯이 `[C-SET-05]` 배치·측정 준비 조건·교정 대상에서 어떻게 취급되는지(빈 슬롯이 있는 홀더로 측정 준비가 가능한지) 명세에서 닫히는지. 탐촉자 설정의 "장착된 탐촉자는 연결 채널을 비울 수 없음"(차단)과 "장착된 탐촉자 삭제는 허용·슬롯 비움"(허용)이 한 문서 세트 안에서 모순 없이 읽히는지.
8. **S7 집계 기준** — 대시보드 `탐촉자 수`(등록 전체)와 같은 화면 `교정` 카드 탐촉자 교정 집계 3종(교정 미완료 · 재교정 필요 · 교정 완료)의 모수가 일치해야 하는지 · 미배선 탐촉자가 '교정 미완료'로 집계되는지 명세에서 정해지는지. `[C-PRJ-04]` DAQ 장비 모니터링 `등록된 탐촉자 N`과 단위가 같은지.

결과는 `80_PROBE_Codex-재검토.md`로. **새 발견이 없으면 이번 라운드 종료.**
