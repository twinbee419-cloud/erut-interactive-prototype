## should-fix

1. **Sight→Bridge PC만 끊겼을 때 ‘즉시 수신 중단’과 현장 수집 지속 사이의 데이터 처리 경계가 없음.** 종합 결과는 DAQ 연결이 끊기면 측정 준비를 즉시 중단하고 진행 중 타일을 처음부터 재진행한다고 함. 알림은 프로그램과 Bridge PC의 연결이 끊겨도 Bridge PC가 데이터를 계속 수집하고 재연결 뒤 누적분을 전송할 수 있다고 함. 연결이 끊긴 동안 Bridge PC가 수집한 데이터와 재연결 직후 뒤늦게 도착한 데이터가 무효 타일·새 타일 기록에 들어가는지 정해지지 않음. **근거:** Notion `[C-PRJ-03] 종합 결과` §▶/■ 측정 준비(연결 끊김·복구), `[C-NTF-01-01] 알림-패널` §연결 실패(끊김)·§알림에 포함하지 않는 항목, `[C-SET-06] 스캔 계획` §참고(파일·재개 단위). **확인 질문:** Sight→Bridge PC 단절 시 `수신 중단`은 Sight 상태만 바꾸는가, Bridge PC의 수집도 멈추는가? 계속 수집된 데이터는 재연결 뒤 폐기·격리·무효 표시 중 무엇으로 처리하고 타일 재진행 데이터와 어떻게 구분하는가?

2. **측정 준비 중 ‘배치 밖 항목 수정 허용’과 ‘DAQ 설정 저장 시 검사 마감’ 규칙의 적용 범위가 다름.** DAQ 트리 문서는 배치되지 않은 홀더·장착되지 않은 탐촉자의 수정을 허용함. 종합 결과는 검사 `진행중`에 `DAQ 장비` 설정을 저장하면 현재 검사를 마감하고 새검사를 만든다고 함. 측정 준비와 검사 진행중은 동시에 성립할 수 있어, 배치 밖 항목만 고쳐도 검사 마감이 발생하는지 불명확함. `현재 배치에 연결된` 판정도 배치 화면의 **저장된 매핑**인지, 저장 전 입력 상태까지 포함하는지 명시되지 않음. 트리 우클릭 메뉴 비활성과 기존 항목의 폼 수정은 서로 다른 조작이라 그 자체의 충돌은 확인되지 않음. **근거:** Notion `[C-SET-02] DAQ 장비-트리 구조(공통)` §좌측 계층 트리(측정 준비 수정 범위), `[C-SET-05] 배치` §저장, `[C-PRJ-03] 종합 결과` §설정 변경 시 검사 마감. **확인 질문:** 수정 가능 판정은 마지막으로 저장된 배치 기준인가? 배치 밖 항목만 저장한 경우에도 진행 중 검사를 마감하는가? 수정 중인 탐촉자의 등록 채널이 수신 대상이면 같은 예외를 적용하는가?

3. **모달·팝업이 열린 동안 F6/F7의 ‘현재 화면’ 판정이 없음.** 공통 문서는 종합 결과·측정 및 교정 화면별로 단축키를 나누고, 교정 화면을 떠날 때 파형 수신을 자동 OFF로 만듦. 하지만 일괄 교정 모달은 교정 화면 **위에** 열리며 자체 ▶/■가 없고, 종합 결과의 연결·측정 준비 불가 팝업도 화면 위에 열림. 이때 F6/F7이 뒤 화면의 토글에 전달되는지, 모달이 가로채는지 적혀 있지 않음. 교정 화면에서 F6으로 파형 수신을 켠 후 **문서 탭 전환** 시 자동 OFF는 명시되어 있어 그 경로는 일치함. **근거:** Notion `[공통] 메뉴바/상태바` §문서 탭·§상태바(F6/F7), `[C-PRJ-05] 측정 및 교정-사이드바` §탐촉자 선택, `[C-PRJ-05-02] 일괄 교정` §진입·제약, `[C-PRJ-03] 종합 결과` §▶/■ 측정 준비. **확인 질문:** 모달·팝업 포커스가 있을 때 F6/F7은 배경 화면에 전달되는가? 일괄 교정 모달 위 F7은 파형 수신을 끄는가? 측정 준비 상태에서 다른 화면의 모달 위 F7도 전역 수신 중단을 실행하는가?

4. **일괄 `[완료]`의 ‘미충족 채널 부분 저장’ 결과 안내가 조건 전체에 연결되지 않음.** 완료 판정은 사이드바의 영점·음속·감도(DGS 포함)·Pulser Control·시험편까지 확장됨. 반면 일괄 모달의 실패 UI는 게이트 미설정 확인 팝업과 ⑤ 시험편 미입력 error만 서술함. 영점·음속·감도·Pulser Control이 미충족이거나 DGS라 기준 에코 기록이 불가능한 채널을 `[완료]`로 부분 저장했을 때, 어느 채널이 왜 미완료로 남았는지 표시·이동 규칙이 없음. 사이드바의 `[교정 완료]`는 미입력 필드를 error로 표시하고 다른 탭이면 자동 전환함. **근거:** Notion `[C-PRJ-05-02] 일괄 교정` §닫기·완료, `[C-PRJ-05] 측정 및 교정-사이드바` §헤더 버튼·§④ 감도 보정(DGS 유효 조건)·§Pulser Control. **확인 질문:** 일괄 `[완료]` 뒤 조건 미충족 채널과 사유를 어디에 표시하는가? 해당 채널의 사이드바 필수 필드로 자동 이동·error 표시하는가? 일괄의 부분 저장은 사이드바 `[교정 완료]`의 미입력 error 처리와 어떻게 다른가?

## 반영 확인

- 대시보드 카드·문서 탭의 측정 준비 차단, DAQ 모니터링 `[연결 해제]` 비활성, F6/F7 화면별 기본 분기, DAQ 단절 뒤 재연결→재교정→▶ 순서, DGS 채널의 일괄 미완료 및 BW 시험편 S/N 면제는 대상 Notion 문서에 반영됨.
- `DAQ 장비 연결 필요` 팝업의 `[설정]`은 `[C-SET-02] DAQ 장비-장비 정보`로 향하지만, 이 문서는 연결 패널이 있는 `[C-SET-02] DAQ 장비-Bridge PC 설정`과 **같은 DAQ 장비 화면의 섹션**임. 별도 화면으로 잘못 이동한다는 불일치는 확인되지 않음.
- 상태바 `DAQ 장비`의 `미연결` 표시는 연결 필요 팝업 조건 및 DAQ 장비 트리의 ‘어느 구간이든 끊기면 빨간 dot’ 규칙과 이어짐. 일괄 `[완료]`의 채널별 완료 판정도 사이드바 필수 조건을 참조하도록 바뀜. 위 4번은 판정값이 아니라 **미충족 결과의 안내** 공백임.
