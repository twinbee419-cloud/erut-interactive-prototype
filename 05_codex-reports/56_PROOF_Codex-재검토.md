## should-fix

1. **DAQ 삭제의 원자 처리 범위가 부수 변경과 `대기` 검사까지 이어지는지 비어 있음.** 진행중 검사 분기는 ‘검사 완료 처리와 장비 삭제’를 하나의 단위로 되돌린다고 하지만, 같은 삭제에서 발생하는 홀더 매핑 해제·스캔 계획 저장 상태 해제는 원자 처리 대상에 명시되지 않음. `대기` 검사 분기는 검사 자체도 함께 삭제하지만 이 분기의 부분 실패·복원 범위도 없음. 근거: Notion `[C-SET-02] DAQ 장비-Bridge PC 설정` §레이아웃 `[삭제]`(진행중 분기·대기 검사·배치/계획 처리), `[C-SET-02] DAQ 장비-트리 구조(공통)` §좌측 계층 트리. **확인 질문:** 삭제 실패 시 장비·검사·배치 매핑·스캔 계획 저장 상태를 모두 원래 상태로 되돌리는가? `대기` 검사 삭제도 같은 단위에 포함되는가?

2. **대기 검사 삭제 후 ‘새 검사 생성’의 실행 주체가 연결되지 않음.** 장비 삭제 문서는 ‘장비 재등록 → 배치 → 스캔 계획 저장 후 새 검사 생성’을 지시하며 생성 규칙을 종합 결과로 보냄. 종합 결과의 생성 규칙은 사용자가 레일의 `[새검사]`를 눌러 즉시 생성하는 동작이며, 재등록 또는 계획 저장 시 자동 생성 규칙은 없음. 근거: Notion `[C-SET-02] DAQ 장비-Bridge PC 설정` §레이아웃 `[삭제]`의 대기 검사 처리, `[C-PRJ-03] 종합 결과` §검사 상태·§새검사, `[C-SET-06] 스캔 계획` §저장. **확인 질문:** 이 흐름의 새 검사는 검사자가 `[새검사]`를 직접 눌러 만드는가, 스캔 계획 재저장 뒤 자동 생성되는가?

3. **다음 타일 수동 버튼의 활성·재개 조건이 두 토글만으로는 확정되지 않음.** 버튼은 ‘현재 타일 검사가 끝난 뒤 클릭’이라고 설명하면서 활성 조건에는 ‘자동 진행 OFF’만 적음. 데이터 수신 중지(▶ 상태), 검사 `대기`·`완료`, 진행 중 타일이 중단돼 시작점부터 다시 해야 하는 상태에서 버튼이 활성인지 없음. 중단 시 재개 단위는 현재 타일이라고 별도 명시됨. 근거: Notion `[C-PRJ-03] 종합 결과` §좌측 아이콘 레일·§검사 상태·§▶/■ 측정 준비 완료, `[C-SET-06] 스캔 계획` §자동화 토글·§참고(파일·재개 단위). **확인 질문:** 수신 허용·검사 진행중·현재 타일 완료 여부를 버튼 활성 조건에 어떻게 묶는가? 중단된 타일이 있으면 다음 타일 진행 대신 그 타일을 재개하도록 어떻게 분기하는가?

4. **교정 주기 만료 차단이 새 수동 버튼에 연결되지 않음.** 스캔 계획은 자동 진행 ON이어도 만료 시 다음 타일을 차단한다고 쓰고, 교정 문서는 만료 시 다음 타일부터 검사 진행을 무조건 차단한다고 씀. 새 `[다음 타일 검사 진행(수동)]`은 자동 진행 OFF일 때 활성이라고만 되어 만료 상태의 버튼·안내·재교정 후 복귀가 정의되지 않음. 근거: Notion `[C-SET-06] 스캔 계획` §자동화 토글, `[C-PRJ-05] 측정 및 교정-사이드바` §교정 주기, `[C-PRJ-03] 종합 결과` §좌측 아이콘 레일. **확인 질문:** 교정 만료 시 수동 버튼도 차단하는가? 사용자는 어떤 안내를 받고, 재교정 후 어떤 타일부터 진행하는가?

5. **일괄 교정 값 저장과 기존 ‘교정 완료’ 유효 상태의 관계가 비어 있음.** 일괄 교정 `[완료]`는 채널별 교정값만 저장하며 `사용 시험편`의 필수 검증은 이후 채널별 `[교정 완료]`에서 수행함. 최초 교정에서는 미완료 채널 때문에 종합 결과 ▶의 ‘전 채널 교정 유효’ 조건을 충족하지 못함. 다만 **이미 교정 완료 이력이 있던 채널**을 일괄 교정으로 다시 조정한 뒤, 일부 채널의 `사용 시험편` 입력·`[교정 완료]`가 남아 있을 때 기존 유효 상태가 즉시 해제되는지는 없음. 근거: Notion `[C-PRJ-05-02] 일괄 교정` §닫기·완료, `[C-PRJ-05] 측정 및 교정-사이드바` §헤더 버튼·§시험편 정보 탭, `[C-SET-06] 스캔 계획` §선행조건. **확인 질문:** 일괄 교정 저장 직후 기존 완료 채널의 유효 상태는 유지·해제 중 무엇인가? 일부 채널의 최종 완료가 남았을 때 ▶ 판정은 어떤 시점의 교정값을 쓰는가?

## 반영 확인

- 삭제 실패 시 검사 완료·장비 삭제를 되돌리는 규칙, 대기 검사 삭제, 측정 중 삭제 비활성은 Notion `[C-SET-02] DAQ 장비-Bridge PC 설정` §레이아웃과 트리 구조 문서에서 확인됨.
- 자동 진행 OFF의 수동 버튼·4그룹 레일은 Notion `[C-PRJ-03] 종합 결과` §좌측 아이콘 레일과 `[C-SET-06] 스캔 계획` §자동화 토글에서 연결됨. 다른 화면설계서의 레일 참조·`[C-HLP-01] 사용 가이드` 아이콘 목록에 3그룹 잔존이나 버튼 누락은 확인되지 않음.
- `사용 시험편`은 채널별 값으로 명시됐고, 일괄 교정 뒤 입력 절차와 다른 탭의 필수 오류 전환이 반영됨. `[C-PRJ-05-01] 교정 이력`의 `[교정 완료]` 참조명 및 `[C-RPT-01] 파형 분석 보고서`의 채널별 `시험편 정보` 출처도 일치함. 교정 이력 화면은 저장된 시험편의 **표시 위치를 약속하지 않으므로**, 화면에 그 필드가 없는 사실만으로 불일치로 분류하지 않음.
