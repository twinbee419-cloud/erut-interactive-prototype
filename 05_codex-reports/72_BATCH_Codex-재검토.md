## should-fix

1. **Echo 미측정에 재사용할 실패 표시가 없음.** 일괄 교정의 `[확인]`은 Echo 미측정을 포함한 측정 실패를 해당 섹션으로 보내고 `파형 영역의 기존 실패 표시`를 재사용한다고 함. 개별 사이드바 ②는 Echo 1·2의 `[측정]` 성공 시 `ToF` 입력만 정의하고, 파형 영역의 인라인 실패 2종은 Gain `[✨]`에만 속함. 게이트 안 피크가 없는 Echo 채널의 오류 위치·문구가 없음. **근거:** Notion `[C-PRJ-05-02] 일괄 교정` §④ 음속·§닫기·완료; `[C-PRJ-05] 측정 및 교정-사이드바` §② 음속; `[C-PRJ-05] 측정 및 교정-파형 영역` §하단 인라인 바—Gain·§게이트 설정 절차. **확인 질문:** Echo 1·2 미측정 채널로 이동하면 어느 행·버튼 옆에 어떤 실패 문구를 표시하는가? 단순 미실행과 피크 검출 실패를 구분하는가?

2. **첫 미완료 채널 자동 선택의 DAQ 장비 전환과 대상 범위가 비어 있음.** 결과 팝업 `[확인]`은 `첫 미완료 채널` 자동 선택만 명시함. 개별 사이드바는 `DAQ 장비 → 해당 장비의 탐촉자` 2단 선택이고, 일괄 모달의 페이지는 배치된 홀더만 보여 줌. 다른 DAQ 장비·홀더의 채널이 첫 미완료일 때 DAQ 드롭다운도 전환하는지, 결과의 `N개/M개`가 현재 홀더 또는 모든 페이지의 채널인지 확인할 수 없음. **근거:** Notion `[C-PRJ-05-02] 일괄 교정` §대상 선택·§닫기·완료; `[C-PRJ-05] 측정 및 교정-사이드바` §탐촉자 선택. **확인 질문:** 완료 판정·첫 미완료 탐색 범위는 현재 홀더인가, 배치된 모든 홀더인가? 선택 채널이 다른 장비에 있으면 DAQ 드롭다운과 탐촉자 드롭다운을 함께 전환하는가?

3. **혼재 홀더에서 Pulser 변경 뒤 기존 감도값을 어떻게 판정하는지 문구가 갈림.** 라디오 미선택 `[완료]`은 `채널별 기존 방식·값으로 완료 판정`이라고 하지만, 같은 세션의 ① Pulser 변경은 ④ 음속과 ⑤ 감도(Gain·TCG·DGS 기준점)를 무효화하며 다시 측정하도록 함. 기존 **값 보존**과 **유효 상태 보존**을 구분하지 않으면 변경 전 감도값으로 완료 처리될 수 있음. 결과 팝업은 사유를 `미충족 항목명`으로만 정의해 `재수행 필요` 상태의 표기도 비어 있음. **근거:** Notion `[C-PRJ-05-02] 일괄 교정` §① Pulser Control·§⑤ 감도·§닫기·완료; `[C-PRJ-05] 측정 및 교정-사이드바` §섹션 간 의존 관계. **확인 질문:** 이 경우 기존 방식·입력값은 유지하되 유효 판정은 실패하는가? 결과 팝업에는 어떤 재수행 사유를 표시하는가?

4. **DGS 일부 칸 덮어쓰기의 부수 변경이 사이드바 규칙과 연결되지 않음.** 일괄 교정은 `입력한 칸만` 전 채널에 덮어쓰고 미입력 칸은 기존 값을 유지한다고 함. 사이드바는 `Ref Type = BW`일 때 `Ref Size`를 비활성화하고 저장값을 `null`로 두며, `Ref Type/Ref Size` 변경 시 기존 기준점 3종을 비움. 따라서 FBH·Ref Size가 있던 채널에 일괄 `Ref Type = BW`만 입력하면 `Ref Size`를 유지하는 규칙과 `null` 규칙이 달라짐. 기준점 삭제도 실제 값이 달라진 채널만인지, 같은 값을 재입력한 채널까지인지 명시되지 않음. **근거:** Notion `[C-PRJ-05-02] 일괄 교정` §⑤ 감도(DGS 설정); `[C-PRJ-05] 측정 및 교정-사이드바` §④ 감도 보정(Ref Size·기준 에코 재기록 조건). **확인 질문:** 일괄 `BW` 선택 시 각 채널의 `Ref Size`와 기준점은 어떻게 처리하는가? 덮어쓴 값이 기존 값과 같은 채널도 재기록 대상으로 보는가?

## 반영 확인

- 최초 교정의 지연 미측정값 `0`과 `Zero = Wedge Delay`는 사이드바의 `Zero = 탐촉자 지연 + Wedge Delay` 정의와 맞음. 방식 전환 시 채널별 TCG·DGS 값 보존도 사이드바 규칙과 맞음. **근거:** Notion `[C-PRJ-05-02] 일괄 교정` §② 영점·§⑤ 감도; `[C-PRJ-05] 측정 및 교정-사이드바` §① 영점·§④ 감도 보정.
- 일괄 모달 하단의 `[닫기]`, 게이트 미설정 확인 팝업의 `[닫기]`는 각각 모달 취소·저장 확인용임. **완료 후 결과 팝업**에는 `[확인]` 1개만 남아 있고, 이전 `[사이드바에서 마무리]` 버튼을 전제로 한 서술은 찾지 못함. Gain 에코 미검출은 파형 영역 Gain `[✨]` 옆 인라인 오류 문구를 재사용할 수 있음. **근거:** Notion `[C-PRJ-05-02] 일괄 교정` §닫기·완료; `[C-PRJ-05] 측정 및 교정-파형 영역` §하단 인라인 바—Gain.
