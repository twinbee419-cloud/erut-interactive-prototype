## 검토할 것

1. **자동 산출식이 구현 가능한 수준으로 정의돼 있는가**
   - 예상 소요 시간 3단계(전체·섹션·타일) · 잘린 구역 비율 · 타일 수 · 섹션 수
   - 문서는 "산출 기반 = 모재 크기 · 타일 크기 · 오버랩 · 이동 속도 · 1회 이동 높이 · 교정 주기"라고만 적습니다. **식이 없습니다.**
   - **섹션이 타일 몇 개 묶음인지 정하는 규칙이 어디에도 없어 보입니다.** 확인해 주세요.
2. **수치 ↔ 비율 양방향 자동 계산 3쌍**(오버랩 · 1회 이동 높이 · 이동 속도)
   - 오버랩은 문서가 이미 *"비율 → 수치 역방향은 타일 수가 오버랩 폭에 다시 종속되므로 반복 수렴 필요 · 산출 방식은 개발 확정"*이라고 적어 **미확정임을 인정**하고 있습니다. 나머지 2쌍도 같은 종속 문제가 있는지 보세요.
   - 어느 쪽을 입력했는지 **저장 시 무엇을 보존하는지**(수치만? 비율만? 둘 다?)가 정의돼 있는지
3. **상수·임계값·단위**가 비어 있는 곳 — 특히 경고 발생 조건
   - `오버랩이 0이면 경고` · `홀더 유효 커버폭 초과 시 경고` · `속도 상한 초과 시 경고` · `잘린 구역 비율이 클수록 재조정 필요`
   - **"클수록"의 임계값**이 없습니다. 다른 경고들의 판정식도 확인해 주세요.
4. **조건 분기의 빈틈**
   - `자동 스캔 장치 연동` OFF일 때 이 화면 전체가 어떻게 동작하는가(토글 1개만 비활성인가, 다른 입력도 영향받는가)
   - 솔루션 유형이 `고정형`인 DAQ가 섞여 있을 때 이 화면의 스캔형 전용 항목들
   - DAQ가 2대 이상일 때 `최대 속도` 기준값은 어느 장비 것인가
5. **예외 4종** — 실패 · 취소·이탈 · 재실행 · 기존 데이터 영향
   - 특히 **저장 후 모재를 바꾸면** 타일 크기·오버랩·산출값이 어떻게 되는가
   - **진행 중인 검사가 있을 때 저장하면** 어떻게 되는가 (`CLAUDE.md`에 "진행중에 저장하면 현재 검사 마감 후 새 검사"라는 규칙이 있습니다 — 이 화면에 반영돼 있는지)
6. **문서 간 값 불일치** — 위 교차 대조 대상과 대조. 같은 항목을 다르게 적은 곳을 "다르다"까지만 보고
7. **선행조건 6가지**가 각 출처 문서에서 실제로 충족 판정 가능한 형태로 정의돼 있는가
