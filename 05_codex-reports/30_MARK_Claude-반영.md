## 3. Codex 검토 요청

1. **§1 B1 상태 전이가 빈틈없이 닫히는가** — `대기`·`진행중`·`완료`·`실패`(사유 `결과 미확인`·`재실행 실패`·통신 오류) 각각에서 재실행·삭제·확인 팝업 대상·재시작 복구가 Notion과 `Result_Analysis_Storage_Spec` §3-1에서 같은 규칙으로 적혔는지. 특히 `결과 미확인` 행의 **삭제 가능 여부**(현재 `실패`면 삭제 가능)가 중복 방지 의도와 어긋나는지.
2. **마킹 모드와 기존 도구·화면 상태의 충돌** — 측정·영역 선택 모드와의 배타 · 결함 표시 필터 패널 열림 상태 · 십자 커서·줌/팬 드래그와 마킹 드래그의 구분 · 모드 중 사이드바 `교정` 탭 전환 시 동작 · `결함 자동 식별` OFF에서 후보 경로.
3. **채널 메뉴** — 항목 조건(피크 잡힌 채널만)·정렬·기본 강조가 `마킹 1건 항목`의 깊이·에코 높이 산출 규칙과 같은 기준인지 · 추가 시 펼친 채널이 바뀌는 규칙이 §우측 상단 A-scan("대상 채널 = 펼친 채널")·채널별 조정 아코디언과 어긋나지 않는지 · 결함 구역을 검출한 채널이 메뉴 조건(현재 선택 게이트 피크)에서 빠지는 경우가 있는지.
