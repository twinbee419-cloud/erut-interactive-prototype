# `67_BATCH` 반영 후 재검토

> Codex · 2026-11-16 · `67_BATCH_Claude-반영.md` §2의 A~C만 검토. 대상 Notion 문서를 새로 읽어 대조함. §3과 기존 미결은 제외. 아래는 어긋남·구현 공백의 발견이며 어느 쪽이 맞는지는 판정하지 않음.

## should-fix

1. **③ Gate의 follow 동작이 ④ 음속의 선행 작업에 의존함.** 새 화면 순서는 `② 영점(Range) → ③ Gate → ④ 음속`이고, ③에서 기준 게이트를 조작하면 다른 채널이 수치를 follow한다고 함. 같은 ③ 문단은 follow 복사에 ④의 `[✨ 탐촉자 지연 적용]`이 선행되어야 한다고 함. ③ 단계에서 게이트를 처음 선택·자동 배치할 때 다른 채널에 즉시 복사하는지, ④에서 지연을 적용할 때까지 대기하는지 정해지지 않음. **근거:** Notion `[C-PRJ-05-02] 일괄 교정` §레이아웃·§② 영점·§③ Gate(게이트 생성·follow 복사 규칙)·§④ 음속. **확인 질문:** 탐촉자 지연 적용 전 ③에서 기준 게이트를 선택·이동하면 follower 채널에는 무엇을 표시·저장하는가? ④에서 지연 적용 후 ③의 수치가 자동으로 전파되는가, 사용자가 ③으로 돌아가 다시 조작해야 하는가?

2. **`적용 규격`의 이력·보고서 표시 위치가 연결되지 않음.** 교정 사이드바는 `적용 규격`을 교정 이력의 기록 항목으로 적고, 표시 위치에 교정 이력과 파형 분석 보고서를 지정함. 그러나 교정 이력의 8개 테이블 열·감도 상세 모달과 파형 분석 보고서의 교정 블록에는 `적용 규격` 항목이 없음. 여러 규격을 입력했을 때 어느 화면·출력물에서 원래 값을 확인할 수 있는지 명세만으로 구현할 수 없음. **근거:** Notion `[C-PRJ-05] 측정 및 교정-사이드바` §Pulser Control 탭·§교정 이력, `[C-PRJ-05-01] 교정 이력` §테이블·§감도 상세 모달, `[C-RPT-01] 파형 분석 보고서` §보고서 구성(교정). **확인 질문:** `적용 규격`은 이력 목록·상세·내보내기와 파형 분석 보고서 중 어디에, 채널별 원문 문자열 또는 규격별 분리 값 중 어떤 형태로 표시·저장하는가?

3. **콤마 입력의 저장·검증 기준이 없음.** 일괄 교정과 개별 사이드바는 모두 `적용 규격`을 직접 입력하고 여러 규격을 콤마로 구분한다고만 함. 일괄 입력 후 교정 상세에서 채널별 수정할 수 있지만, `ISO 16810, ASME Sec. V`의 공백을 보존하는지, `ISO 16810,,ASME Sec. V`·앞뒤 콤마 같은 빈 항목을 허용하는지, 최대 길이와 단일 문자열/목록 중 저장 형식이 정해지지 않음. 화면마다 다른 파싱·검증 결과가 나올 수 있음. **근거:** Notion `[C-PRJ-05-02] 일괄 교정` §① Pulser Control·§교정 상세 모달, `[C-PRJ-05] 측정 및 교정-사이드바` §Pulser Control 탭. **확인 질문:** 구분자 주변 공백·빈 항목·중복 규격을 어떻게 처리하며 최대 입력 길이는 얼마인가? 저장과 채널별 편집은 원문 문자열을 보존하는가, 항목별 목록을 사용하는가?

4. **TCG·DGS가 혼재한 홀더에서 홀더 라디오와 채널별 방식의 관계가 없음.** `⑤ 감도`의 라디오는 홀더 전 채널에 일괄 적용되지만 교정 상세에서 채널별 예외를 허용하고 재교정 시 기존 값을 채움. 그 결과 혼재한 홀더에서는 라디오가 표시할 단일 값이 없는데, `DGS`일 때 DGS 필드를 표시하고 `[✨ TCG]`를 숨기며 `TCG`일 때만 `[✨ TCG]`를 표시함. 예외를 적용한 TCG 채널의 버튼이 숨겨지거나 DGS 채널의 필드가 보이지 않는 조합이 생김. **근거:** Notion `[C-PRJ-05-02] 일괄 교정` §⑤ 감도(섹션 구성·방식 선택·DGS 설정·TCG 버튼)·§교정 상세 모달. **확인 질문:** 채널별 방식이 섞인 홀더의 라디오는 어떤 상태로 표시되는가? DGS 필드와 `[✨ TCG]`의 표시·실행 조건은 홀더 라디오와 각 채널의 실제 보정 방식 중 무엇을 따르는가?

5. **혼재 채널에 `[✨ Gain]`을 일괄 실행할 때 채널별 대상 에코·게이트가 지정되지 않음.** 일괄 버튼은 전 채널의 게이트 피크를 각각 80%로 맞추고, DGS 채널이면 기준점 3종도 기록함. 개별 사이드바에서는 TCG의 첫 에코와 DGS의 `Ref Type` 반사체를 다른 대상으로 다루며, DGS 기준 게이트를 선택해 Gain 대상과 동기화함. 일괄 화면에서는 ③에서 채널별 게이트 선택이 가능하지만, 이 값이 TCG의 첫 에코 게이트와 DGS의 기준 게이트로 각각 쓰이는지, 혼재 상태에서 한 번 누를 때 어떤 채널을 성공·미완료 처리하는지 정의되지 않음. 특히 DGS의 Ref Type·Ref Size가 채널별 예외로 다를 수 있음. **근거:** Notion `[C-PRJ-05-02] 일괄 교정` §③ Gate·§⑤ 감도(`[✨ Gain]`·적용 범위)·§교정 상세 모달, `[C-PRJ-05] 측정 및 교정-사이드바` §④ 감도 보정(TCG 첫 에코·DGS 기준 게이트), `[C-PRJ-05] 측정 및 교정-파형 영역` §하단 인라인 바—Gain. **확인 질문:** `[✨ Gain]`은 채널마다 어떤 게이트·반사체를 대상으로 삼는가? TCG 첫 에코와 DGS 기준 반사체가 동시에 준비되지 않은 채널은 건너뛰고 나머지만 적용하는가, 전체 실행을 중단하는가?

## 반영 확인
