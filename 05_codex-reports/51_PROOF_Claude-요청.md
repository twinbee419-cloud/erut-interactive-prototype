## 2. Codex 검토 요청

### A. 맞춤법·표기 전수

두 대상 전체를 읽고 아래 유형을 찾아 주세요.

1. **오탈자** — 철자 오류·잘못된 낱말(예 이번에 고친 `삐기형`·`재려놓은`).
2. **조사** — 받침 기준 오류(`…으로/로` · `을/를` · `이/가` · `은/는` · `과/와`). 괄호·`<code>`·`\[버튼\]` 뒤 조사는 괄호 앞 낱말 기준으로 판단.
3. **표준 표기** — `-율/-률`(예 `감육율`) · 외래어(예 `맵핑`) · 명백한 띄어쓰기(예 `사용여부`) · `만듬/만듦`류.
4. **중복·반복** — 치환 뒤 같은 명사가 이어지는 곳(예 `파형 분석 보고서 보고서`).
5. **용어 규칙 위반**(정본 = 루트 `CLAUDE.md` §용어)
   - 'DAQ' 단독 잔존. 예외 = 영문 식별자 · 장비명 예시 `DAQ1 장비`
   - '프로브' · 'MC보드' · 'Client'(예외 = 화면ID `C-` 접두 · `Client ID`)
   - 폐기 상태명 '측정 중'(검사 상태 = 대기/진행중/완료)

- **알려진 후보**(도움말에서 발견 · 미수정) — `감육율`(Ⅳ-1) · `맵핑 대상`(Ⅲ-1) · `사용여부(Y/N)`(Ⅲ-8). 화면설계서에도 같은 표기인지, **화면 라벨인지 서술인지** 함께 적어 주세요(라벨이면 Figma도 바뀌어야 하므로).

### B. 모순

1. **문서 내 자기모순** — 같은 문서 안에서 한 요소를 다르게 설명하는 곳(예 이번에 고친 일괄 교정 툴팁: 라벨은 DAQ 장비 선택인데 목록은 홀더라고 설명).
2. **문서 간 불일치** — 같은 항목의 값·명칭·조건이 문서마다 다른 곳.
3. **참조명** — `\[C-ID\] 화면명`의 화면명 ≠ 대상의 현재 문서명.
4. **도움말 v2.0 ↔ 화면설계서** — 도움말이 명세와 다른 동작·명칭·수치·순서를 말하는 곳. 도움말은 검사자용으로 **문장을 새로 쓴 문서**이고 성공 경로만 다루므로 문체 차이·실패 조건 생략은 불일치가 아님 — **사실이 다른 곳만**.
