## should-fix

1. **DAQ 장비 삭제의 두 단계 중 한 단계만 실패한 경우가 비어 있음.** 진행중 검사에서 `[삭제]`를 누르면 검사 완료(마감) **후** DAQ 장비를 삭제하도록 순서가 정해졌으나, 검사 완료 실패 시 삭제 진행 여부와 검사 완료 성공·장비 삭제 실패 시 검사/장비 상태·재시도 방식은 없음. 헤더 `[삭제]`와 트리 `전체 삭제`는 같은 흐름을 가리킴. 근거: Notion `[C-SET-02] DAQ 장비-Bridge PC 설정` §레이아웃 `[삭제]`, `[C-SET-02] DAQ 장비-트리 구조(공통)` §좌측 계층 트리, `[C-PRJ-03] 종합 결과` §검사 상태. **확인 질문:** 완료 처리와 장비 삭제를 하나의 성공/실패 단위로 볼지, 부분 성공 시 사용자에게 어떤 상태와 재시도 동작을 제공할지?

2. **`대기` 검사가 있는 채 DAQ 장비를 삭제하면 그 검사의 처리 대상이 명시되지 않음.** `대기`는 새검사 생성 후 데이터 수집 전의 **검사 1건**인데, 삭제 분기는 `검사 없음 · 대기 · 완료`를 모두 ‘진행중 검사 없음’으로 묶어 공통 모달을 실행함. 삭제 후 배치 매핑과 스캔 계획 저장은 해제하지만, 기존 대기 검사 자체를 유지·폐기·재생성할지는 없음. 수신 중지 직후 데이터가 1건 이상인 검사는 `진행중`으로 남아 경고 모달로 가는 점은 문서 간 일치함. 근거: Notion `[C-PRJ-03] 종합 결과` §검사 상태·§새검사·§▶/■ 측정 준비 완료, `[C-SET-02] DAQ 장비-Bridge PC 설정` §레이아웃 `[삭제]`. **확인 질문:** 삭제 대상 DAQ 장비와 연결된 대기 검사 레코드는 삭제 후 어떻게 처리하는가?

3. **자동 진행 OFF에서 다음 타일로 넘어가는 조작이 연결되지 않음.** 등록 자동화 장비 0건이면 `자동 스캔 장치 연동`이 OFF 고정되고 `다음 타일 검사 자동 진행`도 OFF 고정됨. OFF 설명은 “타일 단위로 멈춰 사용자 확인”이라고 하지만 `[C-PRJ-03]` 좌측 아이콘 레일에는 `다음 타일 검사 진행(수동)`이 없고, `53_PROOF_Claude-반영.md` §3-2는 그 레일의 버튼을 전제함. 근거: Notion `[C-SET-06] 스캔 계획` §자동화 토글, `[C-PRJ-03] 종합 결과` §좌측 아이콘 레일; `53_PROOF_Claude-반영.md:43`. **확인 질문:** 타일 정지 후 확인·다음 타일 진행은 어떤 화면과 조작으로 수행하는가? 저장된 계획에서 장치가 사라지는 경우는 §4의 보류 범위로 보고 여기서 중복 지적하지 않음.

4. **결과 분석 3D 보기에서 캡처 버튼이 남는 서술이 C-scan 2D 전용 범위와 갈림.** `[C-RPT-02]`는 캡처 대상을 `C-scan 2D pane 1개`로 한정했고 `[C-PRJ-03]`도 다른 보기에서 캡처를 숨김. 반면 결과 분석은 `3D View ON`이면 측정 도구를 숨기되 “캡처만 유지”, 3D 절에도 “우상단은 캡처만 표시”라고 적음. `[C-RPT-03]`에는 B·D-scan 캡처 전제가 남지 않았고 나머지 RPT-02 좌표·배지 정정도 확인됨. 근거: Notion `[C-RPT-02] 검사 결과 보고서` §진입·§캡처 생성, `[C-PRJ-03] 종합 결과` §pane 헤더, `[C-PRJ-06] 결과 분석-파형 영역` §좌측 스캔 영역·§3D View. **확인 질문:** 결과 분석 3D 보기의 캡처 버튼은 숨김·비활성인가, 누르면 2D 캡처를 만드는가, 3D 캡처도 허용하는가?

5. **새 `사용 시험편` 필드의 채널 범위와 일괄 교정 후 입력 단계가 불명확함.** `사용 시험편`은 필수이며 교정 이력의 채널별 기록에 포함됨. 다만 채널 선택기는 `교정` 탭에만 있고 `시험편 정보` 탭에는 선택 채널의 값인지 전 채널 공통값인지 명시되지 않음. `[C-PRJ-05-02]`는 채널별 교정값을 `[완료]`로 저장하지만 시험편 입력란은 없고, 모달을 닫은 뒤 개별 미세 조정으로 이어진다고만 함. `[C-RPT-01]`의 `시험편 정보` 출처와 파형 영역 참고의 탭 명칭은 현재 명세와 일치함. 근거: Notion `[C-PRJ-05] 측정 및 교정-사이드바` §탐촉자 선택·§시험편 정보 탭·§교정 이력, `[C-PRJ-05-02] 일괄 교정` §대상 선택·§닫기·완료, `[C-RPT-01] 파형 분석 보고서` §보고서 본문. **확인 질문:** `사용 시험편`의 저장 단위는 채널별인가? 일괄 교정 `[완료]` 후 각 채널의 시험편 정보는 언제 입력하고 어느 `[교정 완료]`에서 필수 검증하는가?

6. **숨겨진 탭의 필수 오류를 어떻게 알려주는지 비어 있음.** `시험편 정보` 탭의 `사용 시험편`은 필수이고, `[교정 완료]`의 미입력 처리는 ‘해당 인풋 필드 error 표시’만 명시됨. 기본 `교정` 탭에서 완료를 눌렀을 때 오류 필드는 다른 탭에 있어 보이지 않음. 근거: Notion `[C-PRJ-05] 측정 및 교정-사이드바` §레이아웃·§헤더 버튼·§시험편 정보 탭. **확인 질문:** 이 경우 `시험편 정보` 탭으로 전환하는가, 탭에도 오류 표시를 두는가, 또는 다른 안내를 제공하는가?
