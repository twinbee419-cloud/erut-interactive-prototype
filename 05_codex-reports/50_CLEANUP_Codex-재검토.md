# 화면설계서 일괄 정리 2차 재검토

## should-fix

1. **DAQ 삭제 시 진행중 검사와 기존 스캔 계획의 상태가 비어 있음.** ① 헤더 `[삭제]`와 트리 `전체 삭제`는 모두 “측정 중지”일 때 허용하고 배치 매핑을 해제하지만, 수신만 중지하고 검사 상태가 `진행중`으로 남은 경우의 처리가 없음. `[C-PRJ-03]`은 DAQ 장비 *설정 저장* 시 진행중 검사를 마감하고 새검사를 만드는 반면 삭제는 저장을 거치지 않음. 기존 스캔 계획의 `저장 완료` 상태를 해제하는지도 없음. ② Notion `[C-SET-02] DAQ 장비-Bridge PC 설정` §레이아웃, `[C-SET-02] DAQ 장비-트리 구조(공통)` §좌측 계층 트리, `[C-PRJ-03] 종합 결과` §검사 상태·§설정 변경 시 검사 마감, `[C-SET-06] 스캔 계획` §저장·§선행조건. ③ 삭제 전 수집한 데이터와 삭제 후의 장비·배치·계획 참조가 한 `진행중` 검사에 남을 수 있음. **확인 질문:** 수신 중지 상태의 `진행중` 검사에서 DAQ 삭제를 허용하는가? 허용하면 검사·원시 데이터·스캔 계획 저장 상태는 각각 어떻게 처리하는가? 트리 메뉴 항목은 측정 중 비활성인가, 숨김인가?

2. **저장된 스캔 계획의 장치 선택이 무효가 된 경우가 정의되지 않음.** ① `자동 스캔 장치 연동` ON에서는 `스캔 장치`가 필수이고 미선택 저장을 차단하나, 이미 저장된 계획에서 선택 장치가 등록 목록에서 사라진 경우 `스캔 계획 저장` 선행조건을 다시 미충족으로 돌리는 규칙이 없음. 등록 장치 0건일 때 셀렉트는 비활성인데 연동 ON의 필수 오류와 어떤 상태를 우선 표시할지도 없음. ② Notion `[C-SET-06] 스캔 계획` §자동화 토글·§저장·§선행조건, `[C-PRJ-03] 종합 결과` §측정 준비. ③ ▶가 저장 여부만 보면 선택할 장치가 없는 자동 주행 계획을 수신 허용할 수 있음. **확인 질문:** 저장 후 선택 장치가 없어지면 계획과 ▶의 `스캔 계획 저장` 판정은 어떻게 바뀌는가? ON·등록 0건에서 필드의 비활성 안내와 저장 오류는 어떻게 표시하는가?

3. **사용 가이드의 최상단 목적 설명과 본문이 반대임.** ① 최상단 설명은 “실제 프로그램 화면 위”에 안내를 겹쳐 보여준다고 하나, §진입은 “실제 화면으로 이동하지 않음”과 “투어 전용 예시 화면”을 명시함. ② Notion `[C-HLP-01] 사용 가이드` §최상단 설명·§진입·§단계 공통 구조. ③ 투어를 현재 실제 화면에 얹을지 별도 예시 화면에 얹을지 개발자가 서로 다르게 읽을 수 있음. **확인 질문:** 최상단 설명도 투어 전용 예시 화면을 기준으로 읽도록 정리할 것인가?

4. **투어 전용 예시 화면의 구현 자료가 완결되지 않음.** ① `[C-HLP-01]`은 샘플 데이터 예시 화면을 6개 단계에 표시한다고 했지만 각 단계의 데이터 값·고정 상태·컨트롤 조작 가능 여부를 정하지 않음. 참고에는 Figma node-id 7개만 있고 파일 URL 또는 file key가 없어 그 ID만으로는 프레임을 특정해 대조할 수 없음. ② Notion `[C-HLP-01] 사용 가이드` §진입·§단계 공통 구조·§참고. ③ 개발자가 예시 화면을 정적 이미지로 넣을지 실제 UI를 샘플 데이터로 렌더할지, 강조 대상을 어떤 상태로 고정할지 확정할 수 없음. **확인 질문:** 7개 Figma 프레임의 파일 링크와 단계별 최종 샘플 데이터는 무엇인가? 예시 화면의 컨트롤은 조작 가능한가, 안내용으로만 표시하는가? 이 검토에서는 node-id와 실제 프레임의 대응을 독립 확인하지 못함.

## nit

1. **화면 ID 뒤에 대응 문서명이 아닌 참조가 1곳 남음.** ① 알림의 연결 실패 후 이동 경로가 `[C-SET-02] DAQ 화면`이라고 적혀 있으나 DB에 그 문서명은 없음. ② Notion `[C-NTF-01-01] 알림-패널` §DAQ 장비 연결 실패; `[C-SET-02]`의 8개 현재 문서명. ③ N1의 “ID 뒤 화면명 = 현재 문서명” 원칙으로는 어느 DAQ 설정 문서를 여는지 특정되지 않음. **확인 질문:** 이 이동의 대상은 `[C-SET-02]`의 어느 문서인가?

2. **치환 후 중복·조사 오류가 남음.** ① `[C-SET-03]`의 `[C-RPT-01] 파형 분석 보고서 보고서 본문`, `[C-PRJ-02]`의 `[C-PRJ-03] 종합 결과으로 이동`은 이어 읽기 어색함. ② Notion `[C-SET-03] 모재` §참고, `[C-PRJ-02] 대시보드` §진행중 검사 카드. ③ 참조명은 맞지만 전달 문구의 품질이 떨어짐. **확인 질문:** 이 두 문장의 중복 명사·조사를 정리할 것인가?
