## 2. Codex 검토 요청

1. **S1 follow 자동 재계산** — 지연 적용 시 follow 위치가 새 Zero 기준으로 재계산되는 규칙이 `모드 전환`(OFF 전환 시 follow 값이 각 채널 값으로 굳음) · 개별 조정 채널 · 재교정 시 기존 값 자동 입력과 충돌하지 않는지 · ④ 일괄 동시 측정과 사이드바 ② 음속(Echo 행마다 측정 게이트를 따로 지정)의 측정 결과가 같은 데이터로 기록되는지.
2. **S2·S3 적용 규격** — 보고서·이력 내보내기·사이드바·일괄 교정·교정 상세가 같은 저장 규칙을 가리키는지 · 다른 문서(예 `[C-PRJ-06]` 결과 분석 · `[C-RPT-02]` 검사 결과 보고서)에 `적용 규격`을 다른 형식으로 다루는 서술이 있는지.
3. **S4 보정 방식 홀더 단위** — 라디오 '선택 없음' 상태에서 ⑤ 버튼 비활성과 `[완료]` 완료 조건(감도 보정 유효) · 결과 팝업 미완료 사유가 이어지는지 · 라디오를 바꿔 전 채널에 적용할 때 사이드바에서 채널별로 입력해 둔 DGS 값·TCG 포인트가 어떻게 되는지(사이드바 '방식 전환해도 각 방식 입력값 유지' 규칙과의 관계).
4. **S5 Gain 대상** — 건너뛴 채널의 미완료 사유가 결과 팝업 · `[사이드바에서 마무리]` 흐름과 맞는지.
