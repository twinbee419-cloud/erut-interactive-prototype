## 2. Codex 검토 요청

> 1~2는 반영 항목 일반 점검 · **3~6은 Claude가 반영하며 확신하지 못한 지점** — 구체적으로 대조해 주세요.

1. **S1·S2·S3 반영 문구** — 일괄 교정 문서 안에서 서로 · 사이드바 ①·④와 어긋나지 않는지.
2. **S4 결과 팝업** — `[확인]` 단일화 후 `[C-PRJ-05-02]` 안에 `[닫기]`·`[사이드바에서 마무리]`를 전제로 한 서술이 남았는지.
3. **Echo 미측정의 '기존 실패 표시'가 실제로 정의돼 있는가** — S4 규칙은 측정·동작 실패면 "파형 영역의 기존 실패 표시 재사용"이라고 했음. Gain 실패는 `[C-PRJ-05] 측정 및 교정-파형 영역` Gain 블록 인라인 에러가 있지만, **Echo 1·2 측정(사이드바 ② 음속 `[측정]`)이 게이트 안 피크를 못 찾았을 때의 실패 표시**가 사이드바·파형 영역 어디에 정의돼 있는지 확인. 없으면 공백으로 보고.
4. **첫 미완료 채널이 다른 DAQ 장비·홀더에 있을 때** — `[확인]` 자동 선택 시 사이드바 `탐촉자 선택`의 DAQ 장비 드롭다운도 함께 바뀌는지 · 일괄 교정의 홀더 페이지네이션(배치된 홀더만)과 사이드바 채널 목록 범위가 같은지 (`[C-PRJ-05]` 사이드바 §탐촉자 선택).
5. **S2 '감도 보정 바꾸지 않음' + 같은 세션의 ① Pulser 변경** — 혼재 홀더에서 라디오 미선택으로 `[완료]`했는데 같은 세션에 ① Pulser Control을 바꿨다면 ⑤ 감도는 무효(§① Pulser Control)가 됨. 이때 채널별 기존 감도 값으로 완료 판정한다는 S2 문구와 무효화 규칙이 충돌하지 않는지 · 결과 팝업 사유가 무엇이 되는지.
6. **S3 '입력한 칸만 덮어씀' + DGS 재기록 트리거** — 사이드바 ④의 '기준 에코를 다시 기록해야 하는 변경 7종' 중 3번 `Ref Type / Ref Size` 변경은 기준점 3종을 비움. 일괄 교정에서 `Ref Type`·`Ref Size` 칸을 입력해 전 채널에 덮어쓰면 **값이 실제로 바뀐 채널만** 기준점이 지워지는지, 같은 값을 다시 입력한 채널도 지워지는지 명세상 구분되는지.
