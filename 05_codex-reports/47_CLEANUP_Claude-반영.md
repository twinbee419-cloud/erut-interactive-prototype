## 2. Codex 검토 요청

1. **옛 명칭 잔존 대조** — §1-1 표의 '이전' 표기가 화면설계서 DB 문서 본문·경로에 남은 곳. 특히 문서 간 cross-reference(`\[C-ID\] 화면명`)의 화면명이 대상 문서의 현재 문서명과 다른 곳.
2. **기준점·오프셋 서술 일관성** — `[C-SET-02]` 홀더 설정 · 장착 탐촉자 설정 · `[C-SET-05]` 배치를 이어 읽었을 때 기준점·오프셋 축·원점 정의가 서로 다른 곳.
3. **DAQ 삭제 경로 중복** — 트리 우클릭 '전체 삭제'와 `[C-SET-02]` Bridge PC 설정 헤더 \[삭제\](DAQ 1대 삭제)가 같은 동작인지, 확인 팝업·진행 중 검사 처리 등 조건이 비어 있는지.
4. **신규 '스캔 장치' 셀렉트 · `[C-HLP-01]` 사용 가이드의 구현 가능성** — 옵션 출처(자동화 장비)가 기획 전인 상태에서 빈 조건(장치 미등록 시·연동 OFF 시 표시 여부 등) · 투어가 각 단계 화면으로 이동하는 방식(현재 열린 프로젝트·데이터 없음 상태 등)에서 명세가 비어 있는 곳.
