## 1. 요약 — 화면 수정이 아니라 '사용 흐름' 설계가 필요한 이유

1. **고정형으로 명시 정의된 것은 6가지뿐**입니다(§2).
2. **검사 엔티티 · 검사 대상 · 모재 연결 · 교정 진입 · 모니터링 그리드 · 캡처 경로는 원래부터 비어 있습니다.** 이 화면들은 모두 '검사 대상 홀더'를 전제로 쓰였고, 홀더가 없는 고정형이 들어갈 길이 없습니다.
3. **Flow v2가 남은 정의도 흔들었습니다.** 배선(연결 채널)이 탐촉자 설정에서 홀더 '탐촉자 구성' 탭으로 옮겨가 홀더 없는 고정형은 배선할 곳이 없습니다. 탐촉자가 장비에 속하지 않게 되면서 '탐촉자 → 장비 → 솔루션 유형' 경로가 사라져, 교정 주기·알림 태그·필터의 고정형 판정이 불가능해졌습니다.
4. **기록 규칙과 화면 경로가 어긋납니다.** 보고서([C-RPT-02] 고정형 표기 6건)와 저장 사양(`holderId // 고정형 = null`)은 고정형 기록이 있다고 전제하지만, 그 기록을 만드는 화면 경로가 없습니다(캡처는 C-scan 2D 전용 · 결과 분석은 완료 검사 · C-scan 전용).
5. **'상시 모니터링'을 누가 맡는지 정해져 있지 않습니다.** 루트 `CLAUDE.md` 제품 분리는 상시 모니터링을 웹 책임으로 두지만, [C-SET-02] 장비 정보는 고정형을 '상시 모니터링 용도'로 적고 있습니다.

- **Q1 + Q3 함께:** 업계의 고정 두께 감시는 보통 **'측정 지점'(CML · TML — Condition / Thickness Monitoring Location)** 단위로 관리합니다. ERUT에 대입하면 '측정 지점 = 모재 + 위치 설명 + 탐촉자 + 연결 채널'이 되어, 배선 위치(Q1)와 감육 판정 기준(Q3)을 한 번에 해결하는 고정형용 '배치'가 됩니다. **01_materials 근거 없음(자료 밖)** — 재개 시 현장 전문가·고객 확인 필요.
- **Q4:** 교정 이력을 남기지 않으면 '실행 시점 만료 체크'(§2-5)의 기준 시각이 사라집니다. 단일 탐촉자 측정(이력 없음)과 같은 [측정] 페이지를 쓰더라도 고정형은 이력을 남기는 쪽이 정합적입니다.
