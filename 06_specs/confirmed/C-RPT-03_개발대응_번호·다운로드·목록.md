### 1-2. 테이블
- `보고서 번호` — 발행 시 자동 부여 · `RPT-P-SCAN-{YYYYMMDD}-{연번 4자리}`(예 `RPT-P-SCAN-20260902-0003`)
  - P = ERUT Sight 발행분([C-RPT-01]과 같은 규칙) · 연번 = 발행일 기준 그날 0001부터 증가 · 재사용 없음
  - 번호 부여 시점 = 발행 확정 때 · 발행 확인 팝업을 [닫기]하면 번호 소비 없음
  - 이전 형식 `RPT-{YYYY}-{연번}`으로 발행된 이력은 번호 · 파일명 그대로 둠
  - PDF 파일명 = `{보고서 번호}_{모재명}_{YYYYMMDD}.pdf`(발행 시 저장되는 원본 · 다운로드 공통) · 모재가 여러 개면 `{첫 모재명} 외 N` · 금지 문자(`\ / : * ? " < > |`) = `_`
- `모재` — 2개 이상이면 `{첫 모재명} 외 N` · 첫 모재 = 이름 오름차순 첫 항목 · hover 시 전체 목록 툴팁

### 1-3. 선택 · 다운로드
- [다운로드] — 선택 0건이면 비활성 · Windows 파일 탐색기(초기 경로 = [C-SET-01] '보고서 저장 경로') · 행 [⤓]도 같음 · 탐색기 취소 = 저장하지 않고 닫힘 · 선택 유지
- 1건 = PDF 1개 / 2건 이상 = ZIP 1개
  - ZIP 파일명 = `검사 결과 보고서_{YYYYMMDD}_{HHMMSS}.zip` · 일시 = 다운로드 시각
  - ZIP 안에 같은 이름의 PDF가 둘 이상이면 둘째부터 ` (2)` · ` (3)` …
- 완료 = 토스트 `총 N개의 파일을 성공적으로 다운로드했습니다.` · N = 저장한 PDF(보고서) 수
- 실패 = `파일을 저장하지 못했습니다. 다시 시도해 주세요.` · 1건 원본 없음 = `원본 파일을 찾을 수 없습니다.` · 여러 건 = 실패분 건너뛰고 성공분만 저장 · `{N}건을 저장하지 못했습니다.` 하나로 안내(원본 없음 포함) · 성공분이 있으면 완료 + 실패 건수 토스트(최대 2개) · 성공 0건이면 실패 건수 토스트만
- 토스트 = 링크 없음 · 3초 · hover 시 유지 · 재발행이 아니라 보관본 전달(변경 없음)
