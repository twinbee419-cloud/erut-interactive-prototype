## 1. 확정 내용 (요지 · 정본 = Notion `[공통] 탐촉자 표기 규칙`)
### 1-1. 이름
- 탐촉자 표시명 = 탐촉자명 > 제품명 > `Probe-0001` · 홀더 = `Holder-01` 입력칸 자동 채움(지우고 저장 = 다음 자동 번호 · `(필수)` 표시 없음) · 슬롯 = `S-03`(알림·오프셋 행 `3번`)
- 자동 번호 = 프로젝트 전체 · 최소 자릿수(홀더 2 · 탐촉자 4 · 넘으면 늘어남) · 숫자 순 정렬 · 삭제 번호 재사용 안 함
- **겹치면 경로 무관 ` (n)`**(직접 입력 · 제품명 대체 · 붙여넣기 · 복사) — 끝의 ` (n)`을 떼고 가장 작은 빈 n · 20자 맞춤 후 재검사 · 직접 입력 시 회색 안내 `같은 이름이 있어 {이름} (n)(으)로 저장됩니다.` · 저장 차단 없음 · 범위 = 탐촉자 같은 장비 안 / 홀더·장비 별칭 프로젝트 전체
- 기록(보고서·캡처·교정 이력·알림·로그) = 기록 당시 이름 · 규칙 도입 시 기존 중복 이름 일괄 ` (n)`

### 1-2. 표기
- 한 검사 안 목록 = `표시명` + 회색 `CH nn` · 파형·게이트·채널 단위 = `CH nn` + hover 표시명 · 듀얼 기준 = 수신 채널
- 알림 스캔형 `{홀더명} · {슬롯}번 · CH {nn}` / 고정형 `{표시명} · CH {nn}` · 2행 모재명 = 알림 페이지의 감육 검출·탐촉자 접촉 불량만
- 이력·보고서 필터 = 개별 드롭다운 모재 › 장비 › 홀더 › 탐촉자(앞 선택이 뒤 목록을 좁힘) · 탐촉자 옵션 = 현재 이름 1개 · 삭제 = `(삭제됨 MM-DD)` · 장비 전체 + 여러 대 = 장비명 그룹 제목 · 거르는 기준 = 기록 당시 ID·홀더 · 여러 탐촉자 기록 = 하나라도 일치
- 장비 맥락 = 구조(트리 · 장비 필터 · 그룹 제목 · 장비 열)로 제공 · '겹칠 때만 장비명' 채택 안 함

### 1-3. 홀더 복사·붙여넣기
- 홀더명 제외 사양~오프셋 · 장착 탐촉자(배선)까지 전부 복사 · 배치·스캔 계획 제외 · 같은 장비에 즉시 저장 · 측정 준비 중 비활성 · 실패 = 부분 생성 없음 + 토스트

### 1-4. 캡처 ([C-PRJ-03] · [C-PRJ-06] → [C-RPT-02])
- **'캡처 1장 = 채널 1개' 폐기** → 1장 = 그 창에 표시된 (채널, 게이트) 조합 전부 · 채널 단위 6종 = 채널마다 · 게이트 값 = (채널, 게이트)마다
- 결함 비율 = 포함 채널별 게이트 초과 영역의 합집합 면적 ÷ 모재 전체 면적 · 캡처 순간 산출 · 발행 후 불변
- 카드·정보 패널 `CH 03 외 N` · 상세 모달 헤더 2행 = 홀더명 + 채널 칩 전부(Figma `7268-108647`) · 발행 팝업 Gain = Digital + Analog 합산(같으면 값 · 다르면 범위) · [C-RPT-03] 채널 수 = (장비 · 탐촉자 · 수신 CH) 고유 조합 수
