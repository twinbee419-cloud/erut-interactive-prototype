- 자동 번호 = 프로젝트 전체 · 최소 자릿수(홀더 2 · 탐촉자 4 · 넘으면 늘어남) · 숫자 순 정렬 · 삭제 번호 재사용 안 함
- **겹치면 경로 무관 ` (n)`**(직접 입력 · 제품명 대체 · 붙여넣기 · 복사) — 끝의 ` (n)`을 떼고 가장 작은 빈 n · 20자 맞춤 후 재검사 · 직접 입력 시 회색 안내 `같은 이름이 있어 {이름} (n)(으)로 저장됩니다.` · 저장 차단 없음 · 범위 = 탐촉자 같은 장비 안 / 홀더·장비 별칭 프로젝트 전체
- 기록(보고서·캡처·교정 이력·알림·로그) = 기록 당시 이름 · 규칙 도입 시 기존 중복 이름 일괄 ` (n)`

### 1-2. 표기
- 한 검사 안 목록 = `표시명` + 회색 `CH nn` · 파형·게이트·채널 단위 = `CH nn` + hover 표시명 · 듀얼 기준 = 수신 채널
