## 1. 확정 내용 (Notion 반영 문안 · 정본 = Notion)

  - 숨긴 상태 = 숨기기 전과 같은 여백 유지 · pane 배치 · 크기 비율 불변
  - 표시/숨김 상태 = 화면 전체에 1개(뷰 탭마다 따로 두지 않음) · 숨긴 상태에서 새로 추가 · 분할한 pane도 같은 상태
  - 저장하지 않음 — .erut 뷰 탭 저장 항목 아님 · 프로그램 실행 중에만 유지(다른 문서 탭 이동 후 복귀 = 유지)
  - 측정 준비 중에도 사용 가능 · 수신 · 기록 · 측정선 · 캡처 데이터와 무관 · 숨긴 동안 도구를 쓰려면 다시 표시

### 1-2. pane 헤더 — A-scan pane 채널 선택
- 채널 선택(A-scan pane · 스캔 유형 칩 왼쪽 · 드롭다운) — 이 pane에 표시할 **채널 1개** 선택
  - 닫힌 상태 = `CH nn` · 옵션 = `CH nn` + 보조 회색 탐촉자 표시명(예 `CH 01` `Probe-0001`)
  - 옵션 = 검사 대상 홀더의 장착 탐촉자 채널(듀얼 = 수신 채널) · CH 순 정렬 · 검사 대상 홀더 안에서 CH ↔ 탐촉자 1 : 1
  - 목록 높이 = 옵션 4개 · 넘으면 세로 스크롤
  - 선택 즉시 전환 · 뷰 탭 'pane별 탐촉자 할당'에 반영 · 같은 채널 재선택 = 무시 · Esc · 바깥 클릭 = 선택 유지
  - 게이트 = 선택 채널에 설정된 게이트 전부 표시(A-scan pane에는 게이트 선택 컨트롤 없음) · 게이트 미설정 = 파형만
  - 검사 대상 미선택(옵션 0건) = 드롭다운 비활성
  - 표시 중인 채널이 옵션에서 사라짐(배선 변경 · 검사 대상 전환 · 탐촉자 삭제) = **pane 비움 + placeholder `채널 선택`**(자동 전환 없음 — 다른 탐촉자 파형을 같은 것으로 오인 방지)
  - 측정 준비 중에도 변경 가능 · 표시 채널만 바뀜 · 수신 · 기록 · 게이트 · 캡처 불변
- 스캔 유형 칩 — 유형 전환 시 채널 선택 변환: A-scan 외 pane → A = 선택 조합 중 CH 순 첫 채널 1개 · A → A-scan 외 pane = 그 채널 + 그 채널의 게이트 전부 · A-scan 외 pane끼리 = 조합 유지
- 채널·게이트 다중 선택 = **A-scan 외 pane(C · B · D · S)** · A-scan pane에는 없음 · 좌 열 = `CH nn` + **보조 회색 탐촉자 표시명**(hover에서 변경)
- 뷰 탭 — pane별 탐촉자 할당 = A-scan pane은 채널 1개 · A-scan 외 pane은 (채널, 게이트) 조합
