## 1. 확정 내용 (Notion 반영 문안 · 정본 = Notion)

### 1-1. 레이아웃 · 목록
- 액션 행 — 좌 [삭제] · [다운로드] · [보고서 발행] / 우 `전체 N건` `선택 N건`
  - [보고서 발행] = 항상 활성(이력 행 선택과 무관 · 탐촉자 선택 모달을 엶) · [삭제] · [다운로드]만 선택 0건이면 비활성
- 페이지네이션 — 하단 중앙 · 페이지당 행 수 = 화면에 들어가는 만큼(최소 1행) · 창 크기를 바꾸면 다시 계산하고 보던 첫 행이 든 페이지로 이동
  - 선택 = 항목 기준 유지 — 페이지를 넘기거나 창 크기 변경으로 다시 계산해도 유지 · `선택 N건` = 모든 페이지 합계 · 헤더 체크박스 = 현재 페이지 항목 기준(모두 선택 = 체크 · 일부 = 부분 선택 표시 · 없음 = 해제)
- 빈 상태 — 이력 0건 · 필터 결과 0건 = **공통 빈 상태(조회형)** — 표 머리글 유지 + 본문 가운데 `조회된 데이터가 없습니다.`

### 1-2. 필터
- 모재 · 데이터 수집 장비 · 홀더 · 탐촉자 기본값 `전체 보기` · 홀더가 없는 기록(고정형 · 단일 탐촉자 측정)은 홀더 `전체 보기`일 때만 포함
- 기록된 모재가 1개면 모재 필터 숨김
- 필터 규칙(`전체 보기` · 옵션 정렬 · 모재 필터 숨김) · 표기 규칙 정본 = [공통] 명칭·표기 규칙

### 1-3. 테이블
- `보고서 번호` — `RPT-P-PROBE-{YYYYMMDD}-{연번 4자리}` · P = ERUT Sight 발행분
  - 연번 = 발행일 기준 그날 0001부터 증가 · 재사용 없음
  - 번호 부여 시점 = 발행 확정([저장]) 때 · 발행 모달을 [닫기]하면 번호 소비 없음
- `모재` — 2개 이상이면 `{첫 모재명} 외 N`(예 `곡판-1 외 1`) · 첫 모재 = 이름 오름차순 첫 항목 · hover = 전체 목록
- `데이터 수집 장비` — 2대 이상이면 `{첫 장비 ID} 외 N`(예 `MCuF-001 외 1`) · 첫 장비 = 이름 오름차순 첫 항목 · hover = 전체 목록

### 1-4. 다운로드
- 행별 [⤓] = 1건 PDF · [다운로드](액션 행) = 체크한 보고서 일괄 · 1건 = PDF 1개 / 2건 이상 = ZIP 1개
- 클릭 시 Windows 파일 탐색기 · 초기 경로 = [C-SET-01] 프로그램 설정 `보고서 저장 경로`(기본 `C:\ERUT_Reports`) · [⤓]도 같음 · 탐색기 취소 = 저장하지 않고 닫힘 · 선택 유지
- 파일명
  - PDF = `{보고서 번호}_{첫 모재명}[ 외 N]_{YYYYMMDD}.pdf` · 모재 1개면 ` 외 N` 생략(예 `RPT-P-PROBE-20261125-0005_곡판-1 외 1_20261125.pdf`) · YYYYMMDD = 발행 일자
  - ZIP = `파형 분석 보고서_{YYYYMMDD}_{HHMMSS}.zip` · 일시 = 다운로드 시각
  - ZIP 안에 같은 이름의 PDF가 둘 이상이면 둘째부터 ` (2)` · ` (3)` …
  - 파일명에 쓸 수 없는 문자(`\ / : * ? " < > |`) = `_`로 바꿈
- 완료 = 토스트 `총 N개의 파일을 성공적으로 다운로드했습니다.` · N = 저장한 PDF(보고서) 수 · ZIP으로 묶어도 안의 PDF 수
- 실패 = 토스트 `파일을 저장하지 못했습니다. 다시 시도해 주세요.`
  - 1건 다운로드 · 원본 PDF 없음 = `원본 파일을 찾을 수 없습니다.`
  - 여러 건 = 원본 없음 · 읽기 실패한 건은 건너뛰고 성공분만 저장 · 실패 건수 토스트 `{N}건을 저장하지 못했습니다.` 하나로 안내(원본 없음 포함 · `원본 파일을 찾을 수 없습니다.`는 띄우지 않음)
    - 성공분이 있으면 완료 토스트 + 실패 건수 토스트(최대 2개) · 성공 0건이면 실패 건수 토스트만(ZIP 만들지 않음 — 개발 사양 §3-3)
- 토스트 = 링크 없음 · 3초 표시 · hover 시 유지

### 1-5. 삭제
- [삭제](액션 행) — 체크한 보고서 일괄 · 선택 0건이면 비활성 · 공통 삭제 모달(헤더 `삭제` + [×] · 본문 `등록된 항목을 삭제하시겠습니까?` / `삭제 후에는 복구할 수 없습니다.` · [닫기] · [확인])
- [확인] — 이력 행과 PDF 파일을 함께 삭제 · 목록 재조회 · 선택 해제
  - PDF가 이미 없으면 이력 행만 삭제 · 다운로드로 다른 위치에 저장한 사본은 대상 아님
  - 실패 = 토스트 `삭제하지 못했습니다. 다시 시도해 주세요.` · 이력 행 · PDF 유지
  - 여러 건 중 일부 실패 = 성공분은 삭제 · 토스트 `{N}건을 삭제하지 못했습니다.` · 실패분 유지
  - 토스트 = 링크 없음 · 3초 · hover 시 유지
- [닫기] · [×] = 삭제 없이 닫기 · 선택 유지 · 삭제한 보고서의 번호는 재사용하지 않음

### 1-6. 발행 모달(2단계) 보고서 번호
- 예상 번호 표시(회색 · `저장 시 확정`) · readonly · [저장]으로 확정할 때 번호 부여 · [닫기] = 번호 소비 없음
- 단일 PC 프로그램이라 예상 번호 = 확정 번호 · 같은 날 다른 발행이 먼저 확정되면 다음 번호로 확정 · 확정 번호는 목록의 새 행에서 확인
