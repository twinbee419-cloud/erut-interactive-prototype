## 1. 확정 내용 (Notion 반영 문안 · 정본 = Notion)

### 1-1. 레이아웃 · 필터
- 카드 그리드 — 열 수 · 행 수 모두 창 크기에 맞춤(최소 1행) · 페이지당 카드 수 = 화면에 들어가는 만큼 · 창 크기를 바꾸면 다시 계산하고 보던 첫 카드가 든 페이지로 이동
  - 선택 = 항목 기준 유지 — 창 크기 변경으로 다시 계산해도 유지(페이지를 넘겨도 유지 · 선택 N건 = 다른 페이지 선택분 포함)
- 필터 — 검사 대상(모재) · 데이터 수집 장비 · 홀더 기본값 `전체 보기` · 홀더가 없는 기록은 홀더 `전체 보기`일 때만 포함 · 기록된 모재가 1개면 모재 필터 숨김
- 빈 상태 — 캡처 0개 · 필터 결과 0개 = **공통 빈 상태(조회형)** — 카드 그리드 자리 가운데 `조회된 데이터가 없습니다.`

### 1-2. 캡처 상세 — PNG 내보내기
- 클릭 시 Windows 파일 탐색기 · 저장 위치 지정 · 취소 = 저장하지 않고 닫힘
- 완료 = 토스트 `총 N개의 파일을 성공적으로 내보냈습니다.` · N = 1(캡처 1건 = PNG 1개)
- 실패 = 토스트 `파일을 저장하지 못했습니다. 다시 시도해 주세요.`
- 토스트 = 링크 없음 · 3초 · hover 시 유지 · 파일명 금지 문자(`\ / : * ? " < > |`) = `_`
- 미표시 항목 — Gain은 보고서 본문에서 확인

### 1-3. 보고서 발행 확인 팝업
- 본문 `선택한 N건으로 보고서를 발행합니다.` + **선택 목록**(`모재` · `데이터 수집 장비` · `홀더` · `연결 채널`) · 1행 = 캡처 1건 · 목록 스크롤
  - 값 = 캡처에 저장된 기록 당시 표시명
  - `연결 채널` = 카드 채널 배지와 같은 `{가장 앞 순번 채널명} 외 N`(예 `CH 03 외 2` · 1개면 `CH 03`)
  - `홀더` = 고정형(홀더 없음)은 `-`
- 발행자 입력(필수) · [닫기] · [확인] · **Gain 칸 · '팝업의 Gain 표시 = 안전장치' 문구 삭제**
- 동결값 '저장과 표시' — 카드 = 결함 비율 / 캡처 상세 모달 = 결함 정보 · 모재 정보(Gain 저장은 그대로 · 표시 위치만 줄어듦)

### 1-4. 저장 · 스코프
- 발행 시 저장되는 보고서 PDF 원본 이름 = `{보고서 번호}_{모재명}_{YYYYMMDD}.pdf`([C-RPT-03] 이력 다운로드 파일명과 동일)
  - 모재가 여러 개면 `{모재명}` = `{첫 모재명} 외 N` · 첫 모재 = 이름 오름차순 첫 항목
  - 파일명 금지 문자 = `_`
- 저장 위치 · .erut 귀속 · 보존 정책 = 개발팀 설계(변경 없음)
