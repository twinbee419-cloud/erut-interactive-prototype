## 1. 확정 내용
### 1-1. 셀
- **셀 1개 = 검사 대상 홀더의 장착 탐촉자 1개**(듀얼도 셀 1개 · 판정 = 수신 채널 기준) · 셀 수 = 장착 탐촉자 수
- 1행 = 탐촉자명(미입력 `CH nn`) · 2행 = `CH 01` + 디자인 시스템 송수신 아이콘(싱글 1개 · 듀얼 송신·수신) · 검사 대상명 없음
- 검사 대상 미선택 = 셀 없음 + 안내 `종합 결과에서 검사 대상을 선택해 주세요.` + 범례 `-`

### 1-2. 상태 점 (수신 중에만 표시)
- 수신 전 · 수신 중단 · 검사 완료 = **점 없음**(두 줄 유지) — 측정하지 않은 채널의 정상 오인 방지
- 정상 51~100 % · 약함 6~50 % · 나쁨 1~5 %(경계 수치 현행 유지)
- **연결 안 됨(회색)** = 수신 중 응답 없음 = 5회 이상 연속 패킷 timeout(`Error_Code_Spec` E201·E501) · 회색은 개발팀 협의(상태어 색 규칙 예외)
- 감육 검출 = 수신 중 · **신호 정상** · 두께 기준 이하일 때만(실시간) · 신호가 정상이 아니면 감육 표시 없음(신호 점만) → 신호를 바로잡아 정상이 된 뒤 다시 판정 · 신호 저하 원인(감육 영향 여부) 판단은 검사자 몫 · 검출 기록 = 알림·로그 · 색 = red_bg (2026-11-25 변경: `신호 확인 필요` 상태 삭제)
- 범례 = 정상 · 약함 · 나쁨 · 연결 안 됨 · 감육 검출 · 수신 중에만 집계

### 1-3. 셀 클릭 → 이동
| 셀 | 이동 | 열릴 때 |
|---|---|---|
| 수신 전 · 정상 | 없음 | — |
| 수신 중단(검사 진행중) · 약함 · 나쁨 · 감육 검출 | [C-PRJ-03] 종합 결과 | 현재 뷰 탭에서 그 탐촉자 채널(듀얼 = 수신)의 A-scan pane 강조 · 없으면 '차트 추가' 목록을 그 채널 강조 상태로(창 자동 추가 없음) |
| 연결 안 됨 | [C-SET-02] 데이터 수집 장비-탐촉자 설정 | 그 탐촉자 leaf 선택 · 측정 중 조회 전용 · 미저장 변경 = 공통 팝업(이동) |
| 재교정 필요 | [C-PRJ-05] 측정 및 교정-사이드바 | 데이터 수집 장비 · 홀더 · 탐촉자 선택 |
| 현재 검사가 완료(마감)된 직후 | [C-PRJ-06] 결과 분석 | 그 검사 불러옴 + 그 탐촉자 채널 아코디언만 · 같은 검사가 열려 있으면 다시 불러오지 않음 |
- 겹치는 경우: 재교정 필요 + 다른 상태(검사 완료 포함) → 측정 및 교정 (감육 검출은 신호 정상일 때만 표시되므로 신호 상태와 겹치지 않음)

### 1-4. 알림 · 로그
- '탐촉자 접촉 불량' 제목 그대로 · 안내 문구 `신호 세기와 커넥터·케이블 연결을 확인해 주세요.` · 하위 행 상태값 = 신호 강도 약함 · 신호 강도 나쁨 · **신호 없음**
- 발생·스택 단위 = 탐촉자 · 합칠 때 하위 행 상태값 = 최신 발생값 · 이전 상태 = 로그
- **단건(1건)도 하위 행 1개 상시 표시**(탐촉자 접촉 불량 · 감육 검출 · 재교정 필요) · 하위 행이 있는 유형은 1건부터 건수 표기 · N회는 하위 행에
- 재교정 필요 하위 행 2행 = 재교정 사유(교정 만료 또는 이벤트명) — **임시** · 아래 미확정
- [C-LOG-01] 기록 대상 = 탐촉자 신호 상태 변경 · E105 · 로그 문구 규칙에 시스템 이벤트 형식 추가
