## 1. 확정 내용 (Notion 반영 문안의 요지 · 정본 = Notion 화면설계서)

### 1-1. 구성 단위
- 데이터 수집 장비 1대 · 홀더 여러 개 등록(8채널 = 빠른 검사 · 5채널 = 자세히 관찰 · 4채널 = 전부 횡파) · 탐촉자 1개는 홀더 1개에만 장착
- **홀더 ↔ 모재 = 1 : 1 배치** · **스캔 계획 = 배치된 모재마다 1건** · **검사 1건 = 홀더 1 : 모재 1 : 스캔 계획 1**
- **검사 대상** = 배치와 스캔 계획을 모두 저장한 모재(+ 그 홀더) · [C-PRJ-03] 헤더에서 1개 선택
- 같은 쉘을 5채널로 다시 보는 작업 = 의심 지점 마킹 → 자동화 장비 제어 페이지 소관(범위 밖)

### 1-2. [C-SET-05] 배치
- 좌 = 홀더 목록 · 우 = 모재(필수) · 배치면 · 오프셋 **x·y** · 각도 **회전** (Figma `9177-90102` 기준 · z·기울기 없음)
- 배치하지 않은 홀더 허용 · 모재가 배치된 홀더만 스캔 계획 작성·검사 대상 선택 가능
- 다른 홀더에 배치된 모재 선택 가능 → 저장 시 **'배치 교체'** 팝업(현행 Figma 문구) · \[확인\] = 기존 홀더 배치 해제 + 관련 모재 스캔 계획 초기화
- 이 홀더의 모재를 바꿔 저장 = 이전 모재 배치 해제·스캔 계획 초기화(현재 검사 대상이 아니면 확인 팝업 없음)
- 저장 직후 '스캔 계획 작성' 안내 팝업 → \[확인\] = 그 모재가 선택된 스캔 계획으로 이동

### 1-3. [C-SET-06] 스캔 계획
- `기본 > 모재` = 편집할 스캔 계획 전환 · 옵션 = 배치된 모재만 · 상태 `저장됨`/`미작성` · `홀더` readonly
- 오버랩 비율·1회 이동 높이 비율 기준 = 선택한 모재의 배치면
- 저장 = 그 모재가 검사 대상 목록에 추가 · 다른 모재 계획 저장은 진행중 검사를 마감하지 않음

### 1-4. [C-PRJ-03] 종합 결과
- 헤더 `검사 대상` 드롭다운(`{모재명} · {홀더명} ({N}ch)`) · **측정 준비 중 선택 불가** · 미선택 = 검사명 `-`
- 검사 대상 전환: 진행중 검사 → 확인 팝업 후 **마감(결과 분석 대상)** · 대기 검사 → 팝업 없이 삭제 · 새 대상의 대기 검사 자동 생성 · 홀더가 바뀌면 `로봇에 {홀더명}을 장착했는지 확인해 주세요.` 문구
- **측정 준비 조건 5가지** = 데이터 수집 장비 연결 · **검사 대상 선택** · 교정 완료(검사 대상 홀더의 장착 탐촉자 전체) · 엔코더 캘리브레이션 · 검사 시작 트리거 설정
- 차트 추가 트리 = 검사 대상 홀더의 장착 탐촉자만
- 새검사 = 현재 검사 대상 그대로 · 대기 상태·미선택이면 비활성
- 설정 변경 시 검사 마감 = 현재 검사 대상의 설정만 · 다른 모재 설정 저장은 마감 없음
- **확인 팝업 1개 규칙(정본):** 우선순위 = 화면 자체 확인 팝업(데이터 수집 장비 삭제 · 홀더 삭제 · 모재 삭제 · 배치 교체) > 현재 검사 대상 해제 > 설정 변경 시 검사 마감 · 위 팝업 하나에 아래 단계 영향 문구 표시 · \[확인\] 1번으로 한 단위 처리 · 마감 문구는 진행중일 때만 · 저장 후 안내 팝업은 규칙 대상 아님
- 검사 대상이 없어지는 경우 4종(검사 대상 홀더 삭제 · 배치 교체 · 검사 대상 모재 삭제 · 데이터 수집 장비 삭제) → '현재 검사 대상 해제' 팝업 · 새 검사 생성 없이 미선택

### 1-5. 연결 채널 · 탐촉자 · 교정
- 홀더를 바꿔 달면 같은 데이터 수집 장비 채널에 꽂힘 → **다른 홀더의 탐촉자끼리 같은 연결 채널 허용** · 같은 홀더 안 중복은 장착 탐촉자 설정에서 차단 · 표시명 `CH nn` 유지
- 장착 탐촉자 옵션 = 다른 홀더에 장착된 탐촉자 제외
- SN = 비어 있는 탐촉자 중 검사 대상 홀더의 탐촉자에만 채움 · 저장된 SN은 덮어쓰지 않음
- [C-PRJ-05] 교정 선택 = **데이터 수집 장비 → 홀더 → 탐촉자** · 검사 대상 선택과 무관 · 저장·보존 단위 = 탐촉자별
- 교정 주기(스캔형) = 선택한 홀더가 배치된 모재의 스캔 계획 주기 · 배치되지 않은 홀더·스캔 계획 저장 전 = 주기 없음
- 판정 범위(스캔형): ⚠ 표시 = 각 홀더 기준 / 재교정 알림·즉시 수신 중단·모니터링 셀 = 검사 대상 홀더만
- 교정 이력 모재 = 선택한 홀더에 배치된 모재(없으면 `-`)

### 1-6. 측정 중 잠금
- 측정 준비(▶ 켬) 중 **[C-SET-02]~[C-SET-06]** 잠금 — 데이터 수집 장비 · 모재 · 모재 프리셋 = 열람 가능·조회 전용(\[저장\]·\[삭제\]·트리 \[+\]·컨텍스트 메뉴 비활성) / 배치 · 스캔 계획 = 진입 비활성 · 보고서·로그·알림·결과 분석 열람 가능

### 1-7. 삭제
- 홀더 삭제 = 그 홀더의 배치 해제·모재 스캔 계획 초기화 · 확인 팝업 `홀더 삭제`
- 모재 삭제 = 배치된 모재도 삭제 가능(배치·스캔 계획 함께 삭제) · 확인 팝업 `모재 삭제`
- 데이터 수집 장비 삭제 = 배치 해제·스캔 계획 초기화 · 검사 대상 미선택(데이터 수집 장비 1대 구성)
- 연쇄 처리는 하나의 단위(실패 시 전부 원래 상태 · `삭제하지 못했습니다. 다시 시도해 주세요.`)
