## 1. 확정 내용 (Notion 반영 문안 · 정본 = 트리 구조(공통) '설정/제어 잠금')

### 1-1. 트리 구조(공통) — 장비 노드 우클릭 `설정/제어 잠금`
- 잠금 시 **설정 편집 및 ▶ 측정 준비 불가** · **■ 수신 중단(F7)은 잠금과 관계없이 항상 가능** · 자물쇠 아이콘 · 잠금 범위 = 그 장비와 하위 I/O 장비(탐촉자 · 홀더는 대상 아님)
  - 잠금이 막는 측정 제어 = **[C-PRJ-03] 종합 결과 ▶ 측정 준비(F6)만** · [C-PRJ-05] 측정 및 교정의 `파형 수신` 토글은 잠금 대상 아님(잠금 범위 = 장비 · 하위 I/O 설정 · 교정값은 탐촉자 기준)
  - 잠금 중 설정 화면 = 그 장비의 데이터 수집 PC 설정 · 장비 정보 · MQTT 설정 · 하위 I/O 장비 설정의 **모든 입력 · [저장] · [삭제] 비활성**(숨기지 않고 비활성 표시) · [불러오기] · [↺] · I/O 장비 [리셋]도 비활성 · [내보내기]는 활성 · 패널 상단 안내 `설정/제어 잠금 중입니다.`
  - 잠금 중 트리 우클릭 = 그 장비의 `I/O 장비 추가` · `이름 바꾸기` · `전체 삭제` · 하위 `I/O 장비` branch의 추가 · 항목 초기화 · I/O 장비 leaf 삭제 비활성 · `설정/제어 잠금` 메뉴만 활성(잠금 상태 메뉴명 `설정/제어 잠금 해제`)
  - 비활성 입력 · 버튼 · 메뉴 hover 툴팁 = `설정/제어 잠금 중에는 수정할 수 없습니다.` · 해제 = 트리에서 그 장비 우클릭 → `설정/제어 잠금 해제`
  - **측정 준비 상태와 함께 걸릴 때** — 비활성 범위 = 두 규칙의 합 · 툴팁 · 패널 상단 안내 = **잠금 안내 우선**(`측정 중인 검사에 쓰이는 항목이라 수정할 수 없습니다.`는 표시하지 않음) · 해제 후 측정 준비 중이면 측정 준비 안내로 전환
  - 연결 · 연결 해제 · 장비 전환 = 잠금과 무관(측정 준비 중 제한은 '측정 준비 상태' 규칙 그대로)
  - 저장하지 않은 입력이 있는 그 장비를 잠그면 `공통 팝업 - 변경 내용 저장`(이동) 먼저 — [저장] = 저장 후 잠금 · 저장 실패 시 잠그지 않음 / [저장 안 함] = 입력 폐기(마지막 저장본 유지) 후 잠금 / [×] = 잠그지 않음 · 입력 유지(정본 = [공통] 메뉴바/상태바 '같은 탭 안에서 내용이 바뀔 때')

### 1-2. 하위 화면
- **데이터 수집 PC 설정 — 헤더 [삭제]** 활성 조건 = 설정/제어 잠금이 아닌 장비 중 연결되지 않은 장비는 항상 · 연결된 장비는 수신 중단 상태에서만 · 비활성 ⓘ 툴팁 — 잠금 중 = `설정/제어 잠금 중에는 수정할 수 없습니다.` / 그 외 = `수신 중단 상태에서만 삭제할 수 있습니다.`
- **데이터 수집 PC 설정 — '설정/제어 잠금 중'** — 중앙 폼 3섹션의 모든 입력 · [저장] · [삭제] · [불러오기] · [↺] 비활성 · [내보내기] 활성 · 패널 상단 안내 · hover 툴팁 · 우측 연결 패널([연결] · [연결 해제] · [재시도] · [처음으로] · MQTT [연결])은 잠금과 무관
- **장비 정보** — 설정/제어 잠금 중 = 이 섹션의 입력 전부 비활성
- **MQTT 설정** — 설정/제어 잠금 중 = 사용 여부 · Host · Port · Username · Password 입력 비활성 · 우측 MQTT 연결 블록 [연결] · [재시도]는 잠금과 무관
- **I/O 장비 설정** — 상위 데이터 수집 장비가 잠금 중 = 모든 입력 · [리셋] · [↺] · [저장] 비활성 · 패널 상단 안내 · hover 툴팁(측정 준비와 함께 걸리면 잠금 안내 우선)
