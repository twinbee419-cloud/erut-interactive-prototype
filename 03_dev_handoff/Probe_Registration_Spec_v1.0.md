## 1. 배경 / 결정

탐촉자 등록 시 **수직형·경사각형 구분은 시리얼 넘버 자동 인식이 아닌 수동 입력**으로 처리한다.
탐촉자 주파수·진동자 규격·굴절각·외형 규격은 **[C-SET-02]에서 등록**한다. 검사체 재질은 **[C-SET-03] 모재**에서 관리하고, PRF·감도 보정 방식은 **[C-PRJ-05] 교정**에서 설정한다.

사용자(기획) 확정 사항:

| 항목 | 결정 |
|---|---|
| 수직/경사각 구분 | **각도 2필드** — 탐촉자 **내부** 각도 = 탐촉자 `굴절각`(횡파만) / 외부 **웨지** = 웨지 `공칭 굴절각`(웨지 미사용 0) · 둘 다 표면 **법선 기준**(0° = 수직). 시리얼 자동 인식 X |
| 파형 유형 | **종파 / 횡파 별도 선택** — 굴절각·깊이 환산에 쓸 음속(V_L / V_S) 결정 · **종파면 탐촉자 `굴절각` 필드 숨김** |
| 탐촉자 주파수 | 개별 수동 입력 필드 (MHz) |
| 진동자 규격 | **형태(원형/사각형)에 따라** 원형 = 직경 1값 / 사각형 = 가로·세로 2값 · mm 수동 입력 |
| 검사체 재질 | [C-SET-03] 모재의 재질을 사용해 음속·권장 PRF 자동 prefill |
| RFP(반응 속도) | = **PRF**(펄스 반복 주파수). 교정 화면에 표시/조정 |
| 감도 보정 방식 | **TCG**(기본) / **DGS** 라디오 택1. DAC는 폐기. 교정 메타 + Amp 진폭보정 기준으로만 저장 |
| 경사각 표준 절차(입사점 BIP·실제 굴절각 검증) | **이번 범위 제외** — 등록 각도 2필드 + 교정 실측 굴절각([C-PRJ-05] ③)만 유지 |

## 2. 탐촉자 등록 입력 필드 ([C-SET-02])

| 필드 | 타입 | 필수 | 비고 |
|---|---|:--:|---|
| 연결 채널 | select | ✔ | DAQ 연결 테스트에서 획득한 채널 중 다른 탐촉자에 등록되지 않은 채널 선택 |
| 시리얼 번호(SN) | text (최대 20자) | – | 탐촉자 고유 번호. **종류 식별에는 사용하지 않음** |

| 필드 | 타입 | 필수 | 비고 |
|---|---|:--:|---|
| **탐촉자 주파수 (MHz)** | number (0.5–20, step 0.25) | ✔ | 신규. 기존 '탐촉자 종류' 프리셋 분해 |
| **형태** | radio (원형/사각형) | ✔ | 기본 사각형 · **아래 진동자 규격·외형 규격의 필드 구성을 결정** |
| **진동자 규격 - 직경 (mm)** | number (1–50, 소수 최대 2자리) | ✔ | **원형일 때만** · 빔을 송·수신하는 능동 소자의 실제 직경. 외형 규격과 구분 |
| **진동자 규격 - 가로 (mm)** | number (1–50, 소수 최대 2자리) | ✔ | **사각형일 때만** · 능동 소자의 실제 가로 치수 |
| **진동자 규격 - 세로 (mm)** | number (1–50, 소수 최대 2자리) | ✔ | **사각형일 때만** · 능동 소자의 실제 세로 치수 |
| 파형 유형 | radio (종파/횡파) | ✔ | 기본 종파 |
| **지연재 음속 (m/s)** | number | – | 진동자 앞면 보호막(지연재) 내부 음속 · 제조사 데이터시트 값 · DGS `Delay Velocity` 승계 원본 · **미등록이면 DGS 선택 불가**(TCG는 무관) |
| **굴절각 (°)** | number (0–89, step 0.1) | ✔ | 탐촉자 **내부**에 각도가 내장된 제품의 값 · 법선 기준 · **파형 유형이 종파면 필드 숨김·필수 검증 제외** |
| **외형 규격 - 직경 (mm)** | number (>0, 소수 최대 2자리) | ✔ | **원형일 때만** · 외장을 포함한 탐촉자 전체 직경. 3D 모델링용 |
| **외형 규격 - 가로 (mm)** | number (>0, 소수 최대 2자리) | ✔ | **사각형일 때만** · 외장을 포함한 탐촉자 전체 가로 치수. 3D 모델링용 |
| **외형 규격 - 세로 (mm)** | number (>0, 소수 최대 2자리) | ✔ | **사각형일 때만** · 외장을 포함한 탐촉자 전체 세로 치수. 3D 모델링용 |
| **외형 규격 - 높이 (mm)** | number (>0, 소수 최대 2자리) | ✔ | 외장을 포함한 탐촉자 전체 높이 치수. 3D 모델링용 |
| **웨지 공칭 굴절각 (°)** | number (0–89, step 0.1) | ✔ | 탐촉자 **외부**에 끼우는 웨지의 굴절각 · 법선 기준 · **웨지 미사용 `0`** · 표기값(0·45·60·70) 그대로 입력 |
| **웨지 가로 · 세로 · 높이 (mm)** | number (≥0) | ✔ | `높이`로 [C-PRJ-05] `Wedge Delay` 자동 산출 · **웨지 미사용이면 `0` 입력 → `Wedge Delay` 0** |

- **두 각도는 동시 입력 허용**(차단·비활성 없음 — 실제 조합을 특정할 수 없음)
- 교정 [C-PRJ-05] ③ 경사각의 **기본값 우선순위 = 웨지 `공칭 굴절각` → `0`이면 탐촉자 `굴절각`** · 최종값은 언제나 교정 실측값

> **도메인 주의 — 공칭 굴절각 ≠ 웨지 경사면 각도**: 시중 탐촉자는 **굴절각**(모재 안 빔 각도)으로 표기되어 판매된다. 웨지 경사면의 물리 각도(입사각)는 다른 값이다 — 45° 탐촉자 입사각 ≈31° / 60° ≈40° / 70° ≈49°(초음파_기초_원리 §7.3). 입력은 굴절각으로 받고, 입사각은 Snell 법칙으로 역산한다: `sin(입사각) = V_wedge / V_material × sin(굴절각)` (V_material은 파형 유형에 맞는 V_L 또는 V_S). 표면 기준(90°=수직)은 45°에서만 두 기준 값이 일치해 60°·70° 탐촉자에서 오입력을 유발하므로 쓰지 않는다.

| 필드 | 타입 | 필수 | 비고 |
|---|---|:--:|---|
| 교정 주기 (일) | number + 전역기본 체크 | – | 기존 |

> 폐기: '탐촉자 종류' 프리셋 select(표준 5MHz∅10 / 고주파 10MHz∅6 / 저주파 2.25MHz∅13). 임의 조합 입력 불가 문제 해소.

## 3. 교정 측정 항목 ([C-PRJ-05] 교정-사이드바)

기존 음속 · 영점(Zero) · Gain (1×3) 에 **PRF · 감도 보정(TCG/DGS) (1×2)** 추가.

> **도메인 주의 — 음속은 두께가 아니라 재질로 결정**: 음속은 재질 고유 물성(밀도·탄성계수)으로 결정되는 상수다. 두께는 음속이 아니라 ToF·PRF·Gate에 영향을 준다. [C-SET-03] 모재의 재질이 주는 음속은 **표준(참조)값**이며, 실제값은 참조 시험편으로 실측해 보정한다(`음속 = 2×시험편두께×1000/ToF`). 표준 음속은 음속 측정값의 초기값으로 사용하며, 온도·grade·압연방향에 따라 ±1~3% 변동 가능하다.

### 3.1 PRF (자동/수동)
- `자동` 토글 ON(기본) → `calcPRF(공칭두께, 재질)` 산출값 표시(readonly)
- 산식: `PRF_max = c / (2 × T_max × N_safety × N_margin)`, 단계 매핑 `[200, 500, 1000, 2000, 4000] Hz` 중 상한 이하 최대값
- **[6] 검사 대상 관리의 PRF 자동계산과 동일 로직** (`window.calcPRF` 재사용 — 상세: `PRF_Auto_Calculation_Spec_v1.0.md`)
- `자동` OFF → 수동 입력

### 3.2 감도 보정 — TCG / DGS 택1

- **보정 방식** 라디오 (필수) — `TCG`(기본) / `DGS`. **DAC는 폐기**
- 선택에 따라 ④ 감도 보정 본문 전체가 교체된다. 두 방식의 입력 항목은 공유하지 않는다.

#### TCG
- **입력 방식** 토글 — `자동`(기본) / `수동`
  - `자동` — `[✨]`(TCG 자동 적용)만 포인트 테이블에 값을 씀 · 테이블 readonly
    - 전제 = 첫 에코를 FSH 80%에 맞춘 상태 · 2·3·N번째 에코도 80%가 되도록 포인트별 Gain 산출
    - **목표 FSH 80% 고정** — 입력 필드 없음
    - 재실행 시 **확인 없이 즉시 덮어씀** — 테이블에 직접 수정한 값이 있어도 동일(자동 버튼을 누른 것 자체가 덮어쓰기 의사)
  - `수동` — `[✨]` 숨김 · 포인트 테이블 직접 편집
  - **두 모드는 테이블 1개를 공유** — 모드별로 따로 보존하지 않음 · **모드 전환 시 테이블 값 유지**(TCG↔DGS 전환과 다름: 그쪽은 보정 방식이 달라 입력값을 따로 보존)
  - `[교정 완료]` 시점의 모드를 교정 이력에 기록
- **첫 에코 80% 맞춤은 파형 영역 Gain 블록의 `[✨]` 소관** — 사이드바에는 Gain 자동 조정 버튼이 없음
- 포인트 테이블 — `ToF`(μs) + `Gain`(dB) · `[+]`/`[🗑]`는 수동 모드에서만
  - `ToF` 출처 — **자동 모드** = `[✨]`가 검출한 각 에코의 피크 위치(첫 행 = 파형에서 선택된 게이트의 피크) / **수동 모드** = `[+]`로 행을 추가할 때 게이트 ToF 자동 입력(수정 가능)
- **적용 지점 = DAQ 수신단(펌웨어).** 포인트를 장비로 전달해 디지타이징 전에 게인을 건다 · **SDK 측 포인트 개수 상한 없음** → UI에서도 상·하한을 두지 않는다
  - 수신단에서 거는 이유 = ADC 다이나믹 레인지. 디지타이징 뒤에 소프트웨어로 올리면 양자화 노이즈까지 함께 증폭됨
  - 따라서 raw는 **TCG가 적용된 상태로 저장**된다(저장 구조 정본 = `Result_Analysis_Storage_Spec`)

#### DGS — 단일 패널

> **정본 = Notion `[C-PRJ-05] 교정-사이드바` ④ 감도 보정 · DGS.** 아래는 그 요약이며 서로 다르면 Notion이 맞다. 필드 구성은 참고한 상용 SW 화면에서 출발했고, `01_materials`(1순위 도메인 자료)에는 DGS/AVG 원리·입력 파라미터가 없다(용어 사전 명칭 1줄뿐).

| 구분 | 필드 | 단위 | 비고 |
|---|---|---|---|
| 탐촉자 승계 | `XTAL Frequency` | MHz | **readonly** — 탐촉자 등록 `주파수` 승계 |
| | `EFF. Diameter` | mm | **readonly** — 탐촉자 등록 `진동자 규격` 승계 · 원형 = 직경 / 사각형 = 가로 × 세로(단일 직경으로 환산하지 않음) |
| | `Delay Velocity` | m/s | **readonly** — 탐촉자 등록 `지연재 음속` 승계 |
| 곡선 | `DGS Curve` | mm | 필수 · 기본 3.00 |
| 기준 반사체 | `Ref Type` | select | `FBH`(기본) / `SDH` / `BW` |
| | `Ref Size` | mm | 필수 · `BW`면 비활성·`null` |
| 기준 에코 기록 | `기준 게이트` + 결과 2칸(readonly) | — | **DGS 모드에서 파형 영역 Gain `[✨]`가 80%를 맞추는 순간** 기준점 3종 저장 = **기준 게이트 · 기준 음로(mm) · 기준 Gain(dB)** · 별도 버튼 없음 · 실패 시 기록 안 함 |
| 감쇠 및 보정(접이식 · 선택 · 미입력 0) | `Ref Atten` | dB/m | 교정 시편 감쇠계수 |
| | `Ampl Corr.` | dB | 마이너스 가능 |
| | `Test Atten` | dB/m | 실제 모재 감쇠계수 |
| | `Transfer Corr.` | **dB** | 보정량 · 거리당 값 아님 |
| 감쇠 및 보정(접이식) | `Offset` | **dB** | 평행 이동량 · 기본 1행 · 최대 4행 · 행 추가/삭제 |

- 승계 3종 중 하나라도 미등록이면 `DGS` 라디오 비활성
- DGS 섹션 안에는 버튼 없음 — 초기화는 사이드바 헤더 `[↺]`(현재 채널 교정 입력값 되돌림)
- 유효 조건 · 기준 에코 재기록 트리거 7종 = Notion 정본 참조

- **스코프 한정 (중요)**: 보정값은 **교정 메타 + 수집 시점 Amp 정규화 기준**으로만 저장·사용한다.
  - 결함 **크기 판정·등급**은 **웹 서비스 책임**. 윈도우 앱은 판정하지 않음.
  - 윈도우 앱은 정규화된 Amp(또는 raw Amp + 보정 파라미터)를 MQTT로 송신, 웹이 sizing 수행.
- 교정 이력에는 보정 방식과 위 전 필드 값을 함께 기록한다.

## 6. 미해결 / 후속 (v20.1+)

- 경사각 채널 **횡파 음속** 자동 테이블 (현재 `SOUND_SPEEDS`는 종파만). 경사각 사용 본격화 시 도입
- 입사점(BIP) 교정 · 실제 굴절각 검증 단계 (NDT 표준 경사각 절차) — 이번 범위 제외
- `Ref Type` 전체 옵션 확정 (현재 `FBH`만 확인 · 자료에는 SDH·FBH·BW 3종이 약어로만 등재)
- `EFF. Diameter` 입력·승계 방식 확정 — 진동자 가로·세로에서 임의 산출하지 않고 제조사 데이터시트의 별도 유효치수로 관리
- 감쇠 3필드 `dB/m` ↔ 자료 기준 `dB/cm` 환산·검증 범위
- `Delay Velocity` 기본값 2500 ↔ 자료의 아크릴 2,730 m/s
